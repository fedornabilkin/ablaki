# Админка мира и сброс кэша — 2026-09-27

Обновление: первый этап редактора опубликован в test со схемой 19, см. [журнал выпуска](world-test-release.md). Следующий, пока не опубликованный этап добавляет [CRUD семи типов объектов, места оборудования и маршрутный RBAC](world-admin-crud.md). Новых миграций нет. Проверки нового этапа не запускались.

## Причина отсутствия раздела

Боковое меню Yii первоначально не содержало пунктов мира. Первый этап добавил один пункт по `p-admin` + `world-manage`. По следующему поручению владельца эта схема заменена общей группой меню, фильтруемой маршрутными правами, как форум и крафт.

В текущем коде нужно явно назначить `/world-admin/*` и нужные CRUD-маршруты через RBAC. Контроллеры больше не обходят mdm route ACL; фиксированного имени роли нет. Для игрового API отдельно используется `world-manage` без обязательного `p-admin`. До выкладки нового этапа test продолжает использовать прежние два права.

## Сброс кэша

Кнопка «Сбросить кэш» в текущем коде доступна по маршруту `/maintenance/clear-cache`. Она отправляет POST с CSRF, вызывает `authManager->invalidateCache()` и `mdm Helper::invalidate()` для кэша прав, маршрутов и меню. Далее выполняется redirect и выводится результат. Действие записывается в application log с ID администратора.

Это адресная инвалидация кэша доступа, не очистка Redis целиком. Сессии, игровая очередь, данные мира, опубликованные правила и feature flags не изменяются. Изменения permissions через SQL при настроенном RBAC cache требуют сброса уже имеющим административный доступ пользователем либо штатной CLI-инвалидации.

## Первый этап редактора построек — BE:D12

- `/world-admin/index`: серверный список объектов, поиск по названию, фильтр типа, 20 строк на страницу, новые ID сверху; диагностика готовности схемы и игровых возможностей.
- `/world-admin/view?id=…`: путь по иерархии, свойства объекта, дочерние объекты и переход к каталогу публичного активного поселения.
- `/world-admin/premises?id=…`: опубликованные и снятые предложения, поиск, фильтр состояния, пагинация; неизменные условия покупки и расширения, версия шаблона и автор.
- `/world-admin/preview?id=…` (POST): публикация навеса/мастерской/дома либо снятие предложения; обязательная причина до 255 символов. Используются текущие WorldPremises и CommandBus, включая правила собственности поселения, feature flags и блокировки.
- `/world-admin/execute` (POST): подтверждение серверного расчёта. Цена, площадь, начальные/предельные места и причина берутся из серверной сессии, а не из редактируемого hidden JSON. Quote действует 300 секунд; digest связывает показанные условия и версии. Повтор использует тот же request key; изменение данных отвергается существующими revision/terms checks. Сессия хранит до десяти последних подтверждений, включая выполненные, для безопасного повтора POST.
- `/world-admin/audit`: поиск по причине, фильтр объекта, 20 строк на страницу, снимки до/после, автор и операция. Публикация и снятие предложения теперь атомарно записываются в `world_audit`, в том числе при вызове прежнего API; прежние записи не восстанавливаются задним числом.

Денежные значения остаются строками с четырьмя десятичными знаками. Дом резервирует площадь под одну койку. Расширение мест использует существующую линейную цену B, 2B, 3B; публикация не изменяет ранее купленные помещения. Снятие предложения не удаляет шаблон, покупки или имущество. Все формы изменений используют POST и Yii CSRF; игровые GET остаются читающими.

## Следующие этапы

BE:D7 реализован следующим CRUD-этапом; его приёмка отложена. Строительство со сроком и отменой реализовано первым срезом D13. Ремонт/снос с сохранением имущества и истории ночлега (D5–D6), детализация экономических API-permissions H1 и общий changeset publish/rollback H2 остаются открытыми.

Приёмка отложена: доступ с каждым сочетанием permissions, GET вместо POST/неверный CSRF, новая и устаревшая версия quote, повтор подтверждения, отрицательные/слишком большие цены и вместимость дома, поиск/пагинация, журнал и неизменность прежних покупок. Пункт меню появится на сервере после выкладки этого кода; очистка кэша прежней версии его не добавляет.
