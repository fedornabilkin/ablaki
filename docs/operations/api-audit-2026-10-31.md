## Охват и результат

Проверены регистрация JSON API всех модулей, создание действий контроллеров и места HTTP-вызова в JS/TS/Vue. До изменений: 310 правил, 24 неработавших назначения. После удаления 23 мёртвых правил, исправления одной action-конфигурации и добавления трёх совместимых POST-методов: **290 правил, 0 отсутствующих действий, 0 точных дублей метода/шаблона**.

На frontend разобрано **379 файлов**, найдено **190 мест HTTP-вызова**, из них 114 достижимы по статическому графу импортов от `main.js`. Это не число уникальных URL и не доказательство выполнения каждой ветви. Динамические адреса раскрываются адаптерами; карта сохраняет исходные выражения. Серверный HTML-интерфейс и админка не включены в число JSON API.

Два конкретных сокращения: история — **2 → 1 запрос**, личные данные персонажа — **3 → 1 запрос**. Одновременные одинаковые чтения нескольких компонентов разделяют одну сетевую операцию; последовательные чтения не кешируются. Фактическая экономия зависит от открытого экрана и состава параллельно смонтированных компонентов.

## Неактивные и исторические части

Маршруты SPA чата и магазина показывают недоступность раздела; старые `api/chat.js`, `api/craft.js` и соответствующие store не входят в активный граф. Там остаются будущие/старые вызовы `chat-room`, `chat-message`, `chat/ws-token`, `craft-item`, `craft-recipe`, `craft-inventory`, `craft-shop`, для которых нет действующих API-контроллеров. Это не работающие дубли текущего крафта мира. Перед включением этих разделов нужны реальные контракты и отдельная приёмка.

Неиспользуемый старый адаптер сапёра содержит `kon-count`; активный клиент использует действующие ставки/историю. `saper/double` и статический `users/data` остаются историческими обработчиками, не рекомендованными новым потребителям. Наличие action в каталоге не означает завершённый продуктовый сценарий. Неиспользуемый модуль `menu-list`, обходивший общий транспорт, удалён.

Совместимые aliases сохранены и описаны отдельно: рабочие адреса не удалялись только из-за сходства названий. Все новые агрегаты используют уже существующую логику чтения и прежние права.
