## Данные и восстановление

Перед установкой сохранён серверный dump `/opt/ablaki-backend-test/backups/world-20261019T193021-20093.dump`. Workflow восстановил его в отдельную временную БД; два прохода установки подтвердили сохранение имущества, кредитов и владельцев. Затем установка завершилась на общем test и запущен worker.

Read-only снимки до и после выкладки подтвердили одинаковые полные хэши таблиц: `persone` — 23 строки, `economy_account` — 55, `craft_inventory` — 112, `credit_transfer` — 23. Общая сумма личных кошельков, счетов мира и неполученных переводов осталась **134959,6000 Cr**. Повтор подготовки не потребовал средств донора и не создал повторного перевода.

Сохранены три конечных заказа, два обеспеченных пула наград, семь команд подготовки, перевод №23 с журналом и три привязки посевов к ревизиям. Кошельки: `fedornabilkin` — 99175 Cr, `Test01` — 696,8 Cr, `MvpTest01` — 250 Cr, `MvpDenied01` — 0 Cr. Открытых строек и работ источников в момент снимка не было; сохранение уже принятых условий таких работ подтверждено локальными проверками, а на стенде не воспроизводилось.

Включены `world_read`, `world_write`, `storage_v2`, `economy_tick`. Просроченных pending-задач, истёкших lease и dead-задач после выкладки нет. Календарь общего test остался прежним: сутки 3600 секунд, ночь последние 900 секунд.

## Проверка API и границы приёмки

Под существующим разрешённым аккаунтом проверены вход, домашний мир, каталог с пагинацией до 100 записей, варианты размещения и числовой счётчик онлайна. API возвращает дому 70 Cr, шалашу 30 Cr. Один запрос каталога со стороны оператора занял 653,3 мс, вариантов размещения — 1131,7 мс; это полное сетевое время, а не сравнение расчётов на одинаковом серверном снимке.

Для `MvpTest01` экономика, состояние старта и история переводов отвечают HTTP 200, чужая история — 403. Для `MvpDenied01` экономика, состояние и команда старта отвечают 403, обычный профиль сайта — 200. При проверке не выполнялись игровые покупки, получение стартового набора, добыча или переводы средств.

Визуальная и клавиатурная приёмка на реальных экранах не выполнена: браузер CUA недоступен (`Browser is not available: iab`). Прогресс добычи проверен клиентскими тестами и контрактами; доступного контрольному аккаунту источника для отдельного чтения на стенде не было. `VITE_WS_URL` в тестовой сборке пуст, подключение WebSocket не настроено; подтверждения работающего чата эта выкладка не даёт. Сохранилось предупреждение сборки о крупном UI chunk.

Ветки production `master` не менялись: backend `bf08acbb13747cfc958faa7425ad37d20bf1b895`, frontend `33792703f531d98dcfc952ad7b1fe32708039f97`. Внешние участники не приглашались. Последующие коммиты с результатами релиза содержат только документацию и отправляются в рабочие ветки без повторного deployment.
