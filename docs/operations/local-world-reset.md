# Локальный сброс мира и крафта

2026-10-07 по прямому поручению владельца пересоздана PostgreSQL `ablaki_local` на `127.0.0.1:55432`. Удалённые test и production не изменялись.

Полная резервная копия: `temp/world-craft-reset/before-reset.dump` в корне общего workspace, вне Git. SHA-256 находится рядом в `backup-sha256.json`. Архив успешно восстановлен в отдельную `ablaki_world_reset_checks` до удаления данных. Временные помощники и отчёты находятся в том же каталоге.

Удалены 187 таблиц мира, крафта, игровых команд, объектной экономики, NPC, производства и развития, а также шесть совместимых представлений. Связи проверены перед сбросом; удаление выполнено одной PostgreSQL-транзакцией с `RESTRICT`, без удаления внешних зависимостей через CASCADE. Из `migration` удалены только записи соответствующих файлов мира и крафта. Личные кошельки, журнал их перевода в точный формат, пользователи, RBAC, форум и другие разделы сохранены. Контрольные суммы и количества строк 38 сохранённых таблиц совпали до и после установки.

Повторно применены 11 миграций крафта и 43 миграции мира. Заполнены каталоги, выполнены проверенные storage rollout и установка финансовых счетов начальной географии. Старых пользовательских предметов, построек, членства, строек, посадок и ключей команд нет. Начальные семь объектов: мир, два региона, четыре поселения. Игрок заново выбирает поселение и получает стартовый набор; вводные данные не выдаются при чтении страницы.

## Помощники текущего workspace

Из корня workspace:

```powershell
# Восстановленная копия, проверки; рабочую БД этот вызов не затрагивает.
& ./temp/world-living-spaces/php/php.exe -c temp/local-backend/php.ini temp/world-craft-reset/run.php ablaki_world_reset_checks reset
& ./temp/world-living-spaces/php/php.exe -c temp/local-backend/php.ini temp/world-craft-reset/behavior.php
& ./temp/world-living-spaces/php/php.exe -c temp/local-backend/php.ini temp/world-craft-reset/verify-install.php
```

`snapshot.ps1` создаёт архив и проверочную БД только если их ещё нет; существующий архив не перезаписывается. Для следующего отдельного сброса нужен новый каталог с новым актуальным архивом, а не повторное использование старого снимка. В `run.php` разрешены только две явно перечисленные локальные базы и точный DSN. Сброс `ablaki_local` требует успешного отчёта проверки, неизменённых исходников и совпадающего хэша архива. Он не включён в запуск приложения или обычные миграции.

Перед сбросом остановлены локальные API 3180, админка 3195 и worker; фронт 5173 оставался запущенным. После установки и проверки сохранности данных API, админка и worker запущены стандартными `temp/local-backend/start-api.ps1,start-admin.ps1`. Кэш схемы локальной БД отключён.

## Проверки

Чистая установка и повтор миграций проверены на локальной PostgreSQL 11.21. 97 проверок общей модели: уровни 1–7, создание, запрет преждевременной активации, строительство, переименование, координаты, исследования и покупка, повтор команд, сохранность прав, восстановление недостающего индекса/колонки крафта без переписывания кодов. Новый старт, исследование соседних ячеек без вступления в профессию и изготовление доски прошли без `NIGHT_CATCHING_UP`; все игровые изменения проверок откатились. Пройдены общая backend-регрессия, PHP 7.3 parser/runtime lint, 282 frontend-теста и production-сборка. HTTP и браузер проверили чистый мир, пустое поселение с доступным стартом, мобильную карту, список/карточку объектов, общий редактор шаблонов, каталог предметов и рецепты. Источники удалённых данных не участвуют.

Эти новые изменения не проверялись на отдельном MySQL/MariaDB-сервере в рамках локального сброса. Исторические миграции не объединялись: их история уже используется другими средами. Дополнительные подсистемы сохранены как совместимые расширения; общий цикл новых объектов использует одну модель и одни команды.
