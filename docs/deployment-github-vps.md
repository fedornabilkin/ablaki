# Деплой backend

Актуальная инструкция: [Production и тестовый деплой](production-test-deployment.md).

Production backend размещается в `/var/www/api.ablakin.ru`, test backend — в `/var/code/ablaki`. Служебные каталоги — `/opt/ablaki-backend` и `/opt/ablaki-backend-test` соответственно. Ранее `/var/code/ablaki` ошибочно считался production-путём; для новых публикаций эта схема больше не применяется.
