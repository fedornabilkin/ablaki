# Первая тестовая публикация миров

По поручению владельца от 2026-09-27 изменения `feature/09-worlds` публикуются в `test`. Production не входит в эту выкладку. Приёмочные игровые проверки остаются отдельным этапом; штатные проверки GitHub Actions сохраняются.

Тестовый workflow после установки крафта вызывает `deploy/world-open-test.sh`. Скрипт допускает только физический checkout `/var/code/ablaki` на ветке `test`, устанавливает десять отдельных миграций миров и начальное дерево, включает registry-флаги чтения/записи и соответствующие `WORLD_READ=1`/`WORLD_WRITE=1` в тестовом `.env`. При изменении флагов пересоздаётся только сервис PHP. Остальные настройки окружения сохраняются. Обычный production workflow этот шаг пропускает.

Интерфейс: http://94.250.251.94:3181/world. Доступны дерево, карта, поиск, переходы между объектами, вступление в поселение и личная стоянка. Все написанные интерфейсы опубликованы в одной версии.

Каноническое хранение и точный кошелёк этим скриптом **не активируются**. Размещение оборудования, мастерская объекта и финансовые действия требуют отдельного переноса существующих данных с остановленными writers, резервной копией и встроенной сверкой. Порядок описан в `world-storage-rollout.md`, `world-wallet-implementation.md` и `world-wallet-activation.md`. Нельзя заменять эти процедуры прямым включением флагов. Шалаш, платные помещения и огород пока не реализованы.

Успех доставки кода и установки схемы следует подтверждать итогом GitHub Actions; этот документ сам по себе не является результатом запуска.
