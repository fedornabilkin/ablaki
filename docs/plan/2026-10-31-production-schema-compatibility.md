# Совместимость production и подготовка обновления

## Цель и контекст

Сверить предоставленную структуру MariaDB production с текущим кодом, подготовить исправления и безопасную первую установку мира. Production условно разрешён владельцем после успешной проверки на временной БД; требуется горячий переход через GitHub Actions. Новый финальный dump с остановкой записи отменён. Исходная версия кода — `feature/09-worlds` / `3a7deef`; [подробный отчёт и порядок](../operations/production-schema-review-2026-10-31.md).

По уточнению владельца старые таблицы создавались вручную: отсутствие их миграций в журнале само по себе не дефект. Установка мира выполняется отдельной командой, без прежней vendor-цепочки.

## Критерии готовности

Полная репетиция на предоставленном дампе и проверенное завершение конкурентных операций перед денежной паузой; полная история новых миграций мира; транзакционные денежные операции; проверенное восстановление; сохранённые пароли/соли, деньги, история и вещи; повтор после сбоя без дублей. Исторически ручные таблицы не требуют фиктивных записей о миграциях. Локальная схема без данных и синтетический успешный прогон не являются допуском к production.
