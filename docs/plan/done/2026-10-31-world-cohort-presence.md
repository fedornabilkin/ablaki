# Групповое развитие, казна и присутствие

Цель: пять одновременно развивающихся новичков проходят 55 шагов за 14–21 день без внешних пополнений; казна управляется шаблоном и выключена у листьев; карта показывает текущее присутствие.

## Группа A: Общий фонд NPC
- [x] A1. Создать отдельную PostgreSQL-копию и пять обычных новых аккаунтов, профинансировать заселение только существующими публичными средствами.
- [x] A2. Пройти полные маршруты с едиными часами и чередованием действий, измерить пики накоплений, ожидание фонда и сроки каждого игрока.
- [x] A3. При необходимости скорректировать профиль и повторить чистый прогон; проверить реальную конкуренцию денежных команд и сохранение денег.

## Группа B: Казна
- [x] B1. Добавить переключатель казны в шаблон и общее правило отключения для узлов без дочерних объектов.
- [x] B2. Применить правило к финансовым операциям/API/UI без удаления остатков, истории и принятых обязательств; бюджет сохранить.
- [x] B3. Проверить изменение шаблона, появление/удаление дочерних объектов и совместимость существующих операций.

## Группа C: Местоположение
- [x] C1. Добавить серверную запись положения и обновление присутствия с проверкой доступа и защитой от повторов/устаревших запросов.
- [x] C2. Показывать собственную позицию и число присутствующих на карточках/карте; освобождать таймеры при уходе.
- [x] C3. Проверить несколько пользователей, переходы, истечение присутствия, закрытые объекты и мобильный вид.

## Группа D: Завершение
- [x] D1. Обновить контракты API, Insomnia, документацию и результаты группового прогона.
- [x] D2. Выполнить backend/frontend проверки, миграцию на локальной копии и проверить локальный интерфейс.

Готовность: все пять маршрутов завершены, сроки и ограничение нагрузки явно зафиксированы; казна и присутствие работают на сервере и в интерфейсе. Удалённая выкладка не входит в задачу.

Результат: пять новых игроков, у каждого 55/55 шагов и 30 объектов за 19,900 дня; свободный фонд NPC на финише 2090,8981 Cr. Проверены серверный регресс, реальные PostgreSQL-гонки, 340 frontend-тестов, сборка и локальный интерфейс. Проверенный профиль опубликован только локально.
