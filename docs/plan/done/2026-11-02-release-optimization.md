# Выбор проверок и быстрый обычный релиз

Цель: не ждать проверок неизменившихся частей приложения и не повторять первоначальный запуск мира. Сохранить проверки игровых операций, целевой MariaDB и совместимости миграций.

## Группа A: План релиза
- [x] A1. Определять изменения относительно последней успешной публикации, включая пропущенные/неудачные релизы. При неопределённости запускать полный набор.
- [x] A2. Пропускать деплой для документации/тестов; выбирать runtime, MariaDB и переносимость по изменениям. Полный прогон оставить ручным и регулярным.
- [x] A3. Отделить обычный production от первоначального запуска и условно выполнять установщики старых модулей.

## Группа B: Проверки и выпуск
- [x] B1. Устранить повтор minimum/full и повтор подготовки совместимых тестовых сценариев без изменения их утверждений.
- [x] B2. Проверить классификацию, отказы и публикацию; прогнать полный CI перед первым выпуском новой схемы.
- [x] B3. Обновить соглашения, опубликовать и зафиксировать результаты.

Готовность: неизменившийся runtime не собирается; nginx не ждёт игрового маршрута; игровые PHP-изменения проверяются на MariaDB; неизвестная база сравнения никогда не сокращает проверки. Production-БД не используется для тестов.

Проверено 2026-11-02: 7 сценариев выбора проверок, 48 прежних и 8 новых сценариев deploy guards; объединённая регрессия событий/крафта. [Полный изолированный CI](https://github.com/fedornabilkin/ablaki/actions/runs/41497787073) и [production CI/публикация](https://github.com/fedornabilkin/ablaki/actions/runs/41499136455) прошли успешно: SQLite, MariaDB 10.1, MySQL 8, PostgreSQL 16, реальные Linux PHP/Composer/nginx и CORS.

Production — `499343c`, база сравнения — предыдущая публикация `c1dfa6d`. Это изменение автоматизации, поэтому первый выпуск намеренно прошёл весь набор. Обычный серверный сценарий не повторял первоначальную конвертацию денег и активацию мира, сохранил Compose оператора; PHP, cron, worker и HTTP проверены. Полная переносимость остаётся самой долгой частью CI; ускорение малых выпусков достигается выбором затронутых проверок, а не отказом от финансовых и конкурентных сценариев.

[Контрольный коммит только документации](https://github.com/fedornabilkin/ablaki/actions/runs/41500397830) завершился за 21 с: minimum, образы, игровые/DB-проверки и deploy пропущены. Production сохранил опубликованную версию `499343c`.
