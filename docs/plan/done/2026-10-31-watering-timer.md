# Компактный полив и время для новичка

## Цель и контекст

По замечанию владельца оставить в кнопке «Полить» и таймер. Морковь новичка растёт пять минут, прежние интервалы 120/60 секунд требовали два коротких полива. Просроченный полив оставался доступен, хотя уже не восстанавливал урожай.

## Группа A: Изменение

- [x] A1. Оставить одну строку таймера, отключать действие при истечении срока даже до ответа сервера.
- [x] A2. Запретить бесполезный просроченный полив на сервере; опубликовать новое стандартное правило новичка 150/150 секунд, сохранив принятые посевы и настройки администратора.
- [x] A3. Проверить границы срока, повтор миграции, платёжные ограничения и интерфейс на компьютере/мобильном.

## Критерий готовности

Один полив новой моркови новичка доступен с 2:30 до 5:00 после посадки. Кнопка содержит только действие и отсчёт; после срока вода/деньги не списываются. Старые посевы не переписываются, удалённые контуры не меняются.
