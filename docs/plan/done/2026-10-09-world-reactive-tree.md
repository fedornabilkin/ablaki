# Реактивное дерево мира и управление ночлегом

Цель: вложенный контракт мира и единое реактивное дерево Vue, оранжевые доступные кнопки, назначение ночлега у выбранной кровати и последние 30 ночей в прокручиваемой модалке.

Контекст: продолжаем текущую рабочую ветку и сохраняем её изменения. БД хранит нормализованные записи и связи; вложенное представление собирается только для открытой ветви, без рекурсивных SQL-запросов и полной загрузки мира.

## Результат проверки

- Frontend: 296/296 тестов (46 файлов), production-сборка; 25 проверок контракта/дерева/ночей, включая сохранение ссылок и реактивность, частичные ветви, удаление, перенос, старые версии и потерю доступа.
- PHP: runtime lint и синтаксический парсер PHP 7.3, шесть затронутых файлов. На локальной PostgreSQL выполнены прежние 68 проверок общей основы и 26 проверок ремонта/мебели/ночлега с откатом. Назначение, отмена и повтор команды проверены реальным доменом; write-ID кровати скрыты у чужого читателя.
- Восемь реальных локальных ветвей: преобразование страницы в дерево добавляет 0 SQL-запросов. Вложенные ответы 14,4–19,2 КБ вместо 16,8–21,5 КБ прежнего envelope. Повторные дочерние DTO не включаются в map.items/breadcrumbs отдельно. Активные работы всех строек выбираются пакетно.
- Браузер: реальные read-ответы локального API, 30 реальных последних ночей, скролл, карта/инспектор кровати, назначение/отмена через изолированный адаптер команд, одинаковые оранжевые доступные кнопки. Навигация и обновления оставляют один document-запрос и тот же SVG. Ширина 390 px, без ошибок JS/Vue/HTTP.
- Контракт и Insomnia обновлены; старые маршруты сохранены. Схема и данные локальной пользовательской БД не изменялись. Изменения применяются в локальном рабочем проекте; удалённая публикация не выполнялась.

Артефакты находятся в `temp/world-reactive-tree/` вне Git. Служебный файл браузерной сессии удалён. Сборка сохраняет прежнее предупреждение о крупных chunks; отдельный TypeScript typecheck в проекте не настроен.
