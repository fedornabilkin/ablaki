# Последовательные этапы выращивания

Цель: отдельные два полива после посадки и понятное состояние грядки без изменения условий уже растущих посевов.

## Группа A: Правила
- [x] A1. Сохранить версию расписания в условиях нового посева; старые циклы обрабатывать по прежним правилам.
- [x] A2. Отделить первый полив от посадки, сохранить суммарный расход воды и плату стандартного цикла.
- [x] A3. Добавить номер полива в read DTO; сохранить транзакции, проверку сроков и идемпотентность.
- [x] A4. Согласовать сценарии развития и экономическую модель с двумя явными поливами.

## Группа B: Проверки
- [x] B1. Проверить два полива, полный/уменьшенный урожай, повтор команд, истечение срока и продажу отдельными партиями.
- [x] B2. Пройти недельный игровой сценарий на изолированной SQLite и цикл на локальной MariaDB.
- [x] B3. Обновить контракт и коллекцию, выполнить lint и CI.

Готовность: новые посевы явно проходят два полива, старые сохраняют сроки, повтор не расходует воду/деньги снова; миграции и изменение текущих посевов не требуются.

## Группа D: Публикация
- [x] D0. Устранить блокировку смены тестовой ветки историческими CRLF-файлами: сохранить изменения в stash, разрешить только остаточное различие CRLF/LF и проверить реальным Git без принудительного checkout.
- [x] D1. Проверить итоговую ревизию в CI и выпустить совместимые backend/frontend; подтвердить результат.
