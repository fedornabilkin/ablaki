# Простой мир

Цель: семь уровней объектов, расширяемые шаблоны, строительство с учётом труда,
единый каталог предметов и обычные Yii CRUD вместо отдельных систем для каждого типа объекта.

Контекст: работа в существующей `feature/09-worlds`; чужие незакоммиченные изменения сохраняются.
Исторические таблицы и оплаченные права не удаляются. Изменения готовятся локально, без выкладки.

## Группа A: Структура
- [x] A1. Вложить крафт в world, собрать связанные подсистемы и маршруты в модуле.
- [x] A2. Разделить API по предметным областям, сохранить адреса существующих чтений.
- [x] A3. Перенести работу с данными в модели.

## Группа B: Модель
- [x] B1. Ввести ActiveRecord объектов и шаблонов, семь уровней и допустимые связи шаблонов.
- [x] B2. Подготовить повторяемую миграцию существующих объектов без удаления данных.
- [x] B3. Реализовать стройку, серверный учёт времени и оплату помощников из бюджета родителя.
- [x] B4. Обеспечить стартовый набор и воспроизводимый seed: мир, два региона, четыре города, шахта.
- [x] B5. Представить события и финансы отдельными моделями.

## Группа C: Интерфейсы
- [x] C1. Добавить CRUD объектов, шаблонов и событий с GridView, ActiveForm, DetailView, поиском и сортировкой.
- [x] C2. Согласовать API и пользовательский вход в упрощённый мир.
- [x] C3. Обновить контракт API и инструкции установки.

## Группа D: Проверки
- [x] D1. Проверить иерархию, шаблоны, старт, строительство, повторы, права и откат оплаты.
- [x] D2. Выполнить PHP lint, регрессионные проверки маршрутов и доступные проверки СУБД.

Критерии готовности: нет обхода шаблонов или создания готовых пользовательских объектов;
деньги и материалы сохраняются при повторе и ошибке; все новые разделы доступны из админки;
ограничения проверок описаны явно.

## Завершение этапа — актуализация 2026-10-15

Группы A–D выполнены в `c03b924` и последующих доработках. Подтверждения: [установка](../../operations/simple-world-install.md), [тестовый выпуск 2026-10-06](2026-10-06-simple-world-test.md), [локальная переустановка](2026-10-07-world-craft-reset.md), [общая основа](2026-10-09-world-common-foundation.md). Проверены PHP lint/совместимость 7.3, SQLite/MariaDB, затем MySQL/PostgreSQL в CI, повтор установки и сохранность имущества. UI/API опубликованы; последняя подтверждённая версия теста — 2026-10-12.

Уточнение B1/B4: исходные семь уровней и связи родителей реализованы для стартового каталога; общая основа 9 октября заменила пользовательские ограничения деревом с глубиной до 32. Seed создаёт мир, два региона, четыре города; шахта представлена строительным шаблоном, а не бесплатной готовой собственностью. Прежние объекты и оплаченные права сохранены. Это принятое развитие модели, а не открытая задача этапа.

Новая экономика в результат этого этапа не входит. Дальнейшая очередь — [закрытый тест](../2026-10-15-world-closed-test.md).
