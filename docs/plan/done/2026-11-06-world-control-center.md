# Управление миром и пополнение NPC из выручки

Цель: регулярное финансирование заработка NPC из реальных продаж и единая удобная административная панель мира.

Принято владельцем: 80% фактически полученной выручки, максимум 500 Cr за московские сутки на стоянку, интервал не менее часа. Неиспользованный остаток переносится. Существующие деньги и зарезервированные зарплаты не списываются повторно; скрытая эмиссия не допускается. Старые продажи не пересчитываются задним числом.

## Группа A: Финансирование NPC
- [x] A1. Добавить журнал выручки и состояние финансирования с настраиваемой долей, интервалом и дневным пределом.
- [x] A2. Учитывать продажи источников, складов и рынка один раз в той же транзакции.
- [x] A3. Пополнять источники периодическим обработчиком, убрать пополнение по запросу игрока и обходы лимитов.
- [x] A4. Проверить интервалы, границы суток, перенос остатка, конкуренцию и сохранность денег.

## Группа B: Административная панель
- [x] B1. Создать единую навигацию и сводки по экономике, NPC, объектам, предметам, крафту и игрокам.
- [x] B2. Добавить фильтры, пагинацию, подробные карточки и переходы к связанным данным.
- [x] B3. Дать администратору ручное исправление сущностей с обязательным комментарием, предварительным просмотром и сохранением изменений до/после.
- [x] B4. Проверить права, устаревшие формы, журнал, мобильную/desktop компоновку и обновить документацию.

Готовность: ограничения нельзя обойти игровыми операциями; панель позволяет найти показатели и исправить данные с объяснением и неизменяемым аудитом. Проверка на изолированных БД и локальном окружении; production не изменять этой задачей.

Завершено 7 ноября 2026. [Инструкция и результаты](../../operations/world-control-center.md): 917 PASS SQLite / 931 PASS MariaDB, гонка двух обработчиков, откат и округление, PHP lint. Локальная PostgreSQL: миграция без изменения денег, ручное сохранение лимита через браузер и возврат 500 Cr, desktop/mobile 390×844. Журналы не переписываются, структурные изменения — через профильный редактор. Выкладка в test/production не входила в пакет и не выполнялась.
