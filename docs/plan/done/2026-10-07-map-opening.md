# Единое открытие ячеек на карте

Цель: выделение одной/нескольких ячеек и исследование/покупка справа; пояснения в поповере, без списка грядок под картой.
Контекст: локальные frontend/API/PostgreSQL; сохранять накопленные изменения и оплаченные права.

## Группа A: Сервер

- [x] A1. Открывать выбранные грядки по явным ID, сохраняя цены, скидки и старые команды количества. Открытые права могут быть непоследовательными; старое количество выбирает следующие оставшиеся закрытые грядки.
- [x] A2. Исследовать пакет ячеек атомарно с проверкой уровня и количества эликсиров. Проверяются все свободные координаты, расходуется эликсир для каждой ячейки выше уровня.

## Группа B: Интерфейс

- [x] B1. Один блок действий справа для всех карт, подсказки под иконкой восклицания. Огород использует сохранённые цены и существующие оплаченные права; остальные карты сохраняют требования исследования.
- [x] B2. Удалить дублирование грядок под картой; сохранить выбор после обновления и отмену старых ответов. Данные профессии также защищены от смены сессии на той же карте.

## Группа C: Проверка

- [x] C1. Проверить точный выбор, повтор команды, откат ошибок, устаревшие ответы, unit-тесты, сборку и браузер. 273 unit-теста, production-сборка, PHP 7.3 parser/runtime lint 61 файла, общая серверная регрессия и 20 проверок PostgreSQL прошли. Непоследовательное открытие, скидка, старый запрос количества, откат частичной выдачи прав и оплаты, пакетное исследование и откат расхода эликсиров проверены в реальной локальной PostgreSQL с общим откатом. Браузер: реальная карта огорода №10, выбор нескольких несоседних грядок, сумма, поповер и отсутствие списка; пакет исследования на стоянке с тем же инспектором, мобильная адаптация без горизонтальной прокрутки.
- [x] C2. Обновить API/Insomnia и документацию. Расширение существующего огорода явно сохранено; примеры включают необязательный bed_ids, описание исследования — пакет cells и расход эликсиров.

Критерий: покупаются/исследуются именно выбранные ячейки; цены и расход определяет сервер; проверки не меняют игровые данные.

Артефакты: корневая `temp/map-opening/`. В браузере экономические preview/execute изолированы контролируемыми ответами; полный серверный execute и повторы отдельно проверены в PostgreSQL с откатом, включая искусственный отказ при выдаче второй ячейки. Оплаченные пользователем между задачами права сохранены.
