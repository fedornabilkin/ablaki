# Одновременная покупка последнего урожая

Цель: проверить покупку последней моркови в мини-складе №92 двумя пользователями и упростить вложенность формы выращивания.

Контекст: локальная PostgreSQL, остаток одна морковь по 0,5 Cr, родительский огород №84. Покупатели должны иметь достаточный баланс и свободные рюкзаки. Две независимые команды получают расчёты до начала соревнования; запуск — в отдельных процессах с общим барьером.

## Группа A: Покупка

- [x] A1. Подготовить двух покупателей и исходный снимок.
- [x] A2. Выполнить конкурентную покупку, доказать пересечение запросов, проверить одного получателя и один платёж родителю.
- [x] A3. Повторить обе команды и убедиться в отсутствии новых списаний и выдач.

## Группа B: Интерфейс

- [x] B1. Объединить заголовок и содержимое посадки в одну панель без внутренней рамки.
- [x] B2. Проверить форму во встроенном браузере, выполнить проверки и сохранить отчёт.

Готовность: один покупатель получает одну морковь за 0,5 Cr, другой сохраняет баланс; казна огорода получает 0,5 Cr один раз; повтор не изменяет результат.
