# Исправление рейтинга и восстановления крафта на production

Цель: устранить Rating write failed и блокировку мастерской после неудачной операции, сохранив рейтинг, историю и деньги.

## Группа A: Рейтинг
- [x] A1. Сопоставить ошибку с legacy FLOAT в production-копии.
- [x] A2. Расширить точность без изменения прежних значений; проверить миграцию и повторные начисления на копии.
- [x] A3. Проверить атомарность и повторы на целевых БД.
- [x] A4. Применить только проверенную миграцию с временной блокировкой записей и сверкой данных.
- [x] A5. Подтвердить итоговую схему, снятие паузы и работу фонового процесса независимым read-only аудитом.

## Группа B: Крафт
- [x] B1. Воспроизвести невозможность выбора рецепта после ошибочного действия мира.
- [x] B2. Оставить просмотр рецептов доступным и явно показывать безопасное восстановление прежнего запроса.
- [x] B3. Проверить восстановление и выпустить frontend.

Готовность: проверки проходят, рейтинг и история сохранены, повтор не дублирует награду; мастерская показывает причину блокировки и способ продолжения.

Локальная копия MariaDB 10.1.48: исходный FLOAT воспроизводит `Rating write failed` на последовательных наградах. Расширение до DOUBLE и повтор миграции заняли 14,13 с вместе со сверками: значения всех 24 849 профилей и 505 775 записей истории сохранены. Серии из шести наград и их повторов при рейтинге 514.911, 2000 и 4000 прошли; деньги не менялись. DOUBLE сохраняет прежние binary32 значения без округления и позволяет удерживать новые прибавки с точностью политики рейтинга.

Production backend: `c1dfa6dc9b12437b42f64f9fea1d9bcf79fd5305`, [Actions 41306364569](https://github.com/fedornabilkin/ablaki/actions/runs/41306364569). Полные SQLite/MySQL 8/PostgreSQL 16, отдельная MariaDB 10.1.48, runtime PHP 8.3.36 и проверки выпуска прошли. Между независимыми CI-наборами очищаются только таблицы и представления строго выделенной loopback-базы `ablakin_ci`; live DSN отклоняется до подключения.

Применена только `m261101_130000_world_rating_precision`; прежние миграции, Compose, баланс и настройки мира не переписывались. На production сверены все значения 24 849 профилей и 505 778 строк истории, контрольные суммы до/после совпали. Миграция завершена 2026-11-01 12:30:25 UTC; worker и cron возобновлены, временная пауза снята в 12:30:32 UTC. Повтор после частичной DDL сохраняет baseline и продолжает только ту же проверенную ревизию.

Frontend `e37d235ab7d61fe2f82550f35ed55848b2d97f25` опубликован и подтверждён публичным SHA; 484 проверки прошли. Проверки игрового поведения выполнялись в изолированных БД и на локальной копии, не на production.
