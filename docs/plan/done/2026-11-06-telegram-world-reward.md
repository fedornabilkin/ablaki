# Подарок за Telegram и восстановление выращивания

Цель: мотивировать привязку сопоставимыми наборами и дать игроку ежедневный способ снова получить семена.

Контекст: исходные примеры наград неравнозначны. Уже привязанные аккаунты тоже должны получить подарок. Вход и бот сохраняют поведение.

## Группа A: Правила и backend

- [x] A1. Рассчитать четыре набора с разбросом цены до 5%.
- [x] A2. Закрепить псевдослучайный вариант без повторного розыгрыша.
- [x] A3. Выдавать один подарок на аккаунт и Telegram с квитанцией и откатом при переполнении.
- [x] A4. Добавить ровно одну морковь ежедневно, включая дни после стартового пособия.
- [x] A5. Подготовить повторяемые миграции с сохранением опубликованных настроек.

## Группа B: Интерфейс и проверки

- [x] B1. Показать общую карточку в профиле и заданиях мира.
- [x] B2. Закрывать задание после получения, сохранить повтор при потере ответа.
- [x] B3. Проверить повтор, переполнение и перенос Telegram между аккаунтами.
- [x] B4. Проверить параллельные команды на MariaDB и восемь дней снабжения.
- [x] B5. Проверить получение локальным пользователем, мобильные 375 px и документацию API.

Критерий готовности: предметы не теряются/дублируются, привязка не зависит от рюкзака, интерфейс отражает серверное состояние. Достигнут локально; production-выкладка новых экономических правил в этот этап не входит.
