# Главная админки, общий вход и единый крафт мира

Цель: сделать управление понятным человеку, проверить единый пароль сайта и админки и убрать подтверждённые остатки старого крафта без потери игрового функционала.

## Группа A: Вход
- [x] A1. Объединить проверку современных и старых паролей, сохранив запреты заблокированным аккаунтам и исходные хэши.
- [x] A2. Проверить один аккаунт/пароль через обе формы на изолированной базе.

## Группа B: Админка
- [x] B1. Переработать главную страницу с повторно используемыми сводками мира и блоками сайта.
- [x] B2. Подсвечивать текущий пункт меню и раскрывать его родителей, убрать демонстрационные элементы темы.
- [x] B3. Использовать общий показ связанных сущностей: имена, логины и ссылки в списках, карточках и формах.

## Группа C: Крафт
- [x] C1. Проследить актуальные маршруты, каталог, инвентарь и изготовление; описать, что действительно общее с миром.
- [x] C2. Удалить неиспользуемые страницы/компоненты старого фронтенда, сохранить рабочие маршруты и совместимые перенаправления.
- [x] C3. Убрать дублирующую навигацию админки и сохранить необходимые редакторы каталога мира.

## Группа D: Проверка
- [x] D1. Пройти затронутые тесты, сборку frontend и проверку desktop/mobile во встроенном браузере.
- [x] D2. Обновить документацию, завершить план и отправить проверенные изменения в рабочие ветки. Выкладка в test/production в текущую задачу не входит.
