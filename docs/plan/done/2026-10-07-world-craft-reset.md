# Чистый локальный мир и основа MVP

Цель: пересоздать локальные мир и крафт из миграций, устранить ошибки чистой установки и обеспечить общий цикл работы с объектами на всех уровнях.
Контекст: разрешён полный сброс локальных игровых данных; пользователи и остальные разделы сохраняются. Удалённые базы не затрагиваются. Перед сбросом сохраняется полный дамп.

## Группа A: Проверка установки
- [x] A1. Определить таблицы, зависимости и историю миграций мира и крафта; сохранить локальный дамп.
- [x] A2. Выполнить чистую установку на отдельной локальной копии и исправить обнаруженные ошибки миграций.

## Группа B: Общая основа
- [x] B1. Проверить создание, размещение, просмотр, изменение и навигацию объектов разных уровней; устранить ограничения, основанные только на уровне.
- [x] B2. Описать общий цикл объектов и границы расширений без новой кастомизации.

## Группа C: Локальный сброс
- [x] C1. Остановить локальные обработчики, пересоздать согласованный набор таблиц и повторно применить миграции и стартовые справочники.
- [x] C2. Проверить сохранность остальных данных, API, админку и фронт, возобновить локальные сервисы.

Критерии готовности: старых игровых объектов и команд нет; установка повторяема; общий объектный цикл проверен; проверки и путь к резервной копии зафиксированы.

## Результаты

Дамп `temp/world-craft-reset/before-reset.dump` восстановлен в отдельную `ablaki_world_reset_checks`. Рабочая `ablaki_local` пересоздана только после успешной репетиции: удалены 187 доменных таблиц и шесть совместимых представлений; повторно применены 11 миграций крафта и 43 мира. Сохранность 38 остальных таблиц подтверждена количеством строк и контрольными суммами до/после установки. Пользователи, RBAC, форум, личные кошельки и их история сохранены. Остались семь стартовых объектов географии, пустые рюкзаки; членство, стройки, посадки и старые команды очищены.

Новые объекты используют одну карту 5×5 и одинаковые права/стройку на уровнях 1–7. Первый уровень исследования доступен без вступления в профессию. Тип и допустимые родители задаются шаблонами, без фиксированных запретов по уровню. Существующие оплаченные права и размеры сохраняются при обычной миграции; исторические миграции не объединяются и не удаляются в других средах. Миграции расширения крафта и переключателя оплаты возобновляют частичный DDL без переписывания кодов и повторной вставки meta.

Пройдены 97 PostgreSQL-проверок, общая backend-регрессия, PHP 7.3 parser/runtime lint, 282 frontend-теста и сборка. Реальный новый старт и крафт доски проверены на отдельной локальной БД с откатом. HTTP и Chrome проверили мир, пустое поселение, доступный старт, мобильную ширину, списки/карточки/редактор админки, предметы и рецепты. Локальные API 3180, админка 3195 и worker возобновлены; фронт 5173 работает. Новые изменения не проверялись на отдельной MySQL/MariaDB в этом запуске; удалённые среды не изменялись.
