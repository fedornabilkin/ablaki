# Темп раннего мира и городской рынок NPC

Цель: сохранить доступный старт, дать нынешнему набору объектов более длинную траекторию развития и запустить простой конечный рынок без торговли между игроками.

Целевой темп: старт за 3–5 дней, нынешний каталог за 2–3 недели при регулярной игре и доступном финансировании NPC. Это расчёт, не гарантия и не повтор полного маршрута.

Контекст: каталог — начало будущего мира. Крупным стройкам нужна реальная трудоёмкость и польза от найма. Дешёвый выкуп сам по себе не сжигает деньги: отдельная комиссия должна уменьшать суммарные Cr с записью в журнале. Новые правила не переписывают уже принятые стройки, посевы и чужие настройки без публикации профиля.

## Группа A: Баланс

- [x] A1. Пересчитать весь доступный каталог: цена, материалы, длительность, прочность.
- [x] A2. Согласовать обычную и учебную морковь: рост, два полива, окна действий.
- [x] A3. Проверить стоимость полного каталога, старт и темп заработка; отделить расчётную оценку от фактически пройденного игрового маршрута.
- [x] A4. Применять новую прочность только к новым объектам; сохранять принятые условия текущих операций.

## Группа B: Рынок

- [x] B1. Ввести рыночные цены и явное распределение: товар, доставка/сжигание, город, владелец.
- [x] B2. Хранить товар в каноническом инвентаре; пополнять периодически из реального склада NPC, оставляя часть для дешёвой покупки на месте.
- [x] B3. Реализовать покупку и продажу NPC с конечными товарами/деньгами, подтверждением цены, общими квотами и повтором без дублирования.
- [x] B4. Добавить компактный интерфейс рынка города с поиском, остатками и подтверждением суммы.

## Группа C: Проверка и документация

- [x] C1. Проверить откат при переполнении/недостатке денег и гонку за последним товаром.
- [x] C2. Проверить сохранение суммы предметов и денег за вычетом явного сжигания.
- [x] C3. Проверить миграции, сборку, API-контракт и мобильный интерфейс.
- [x] C4. Обновить API-коллекцию, правила баланса и порядок публикации; отправить рабочие ветки без production-выкладки.

Готовность: доступный старт, понятные долгие цели, обеспеченная торговля и доказуемое движение ресурсов. Старый полный план рынка с P2P остаётся отдельным этапом.

Проверено локально: 373 unit-теста frontend и сборка; PHP lint; API-каталог 292 маршрута без дублей; регрессия профиля/экономики; гонка двух покупателей на MariaDB; покупка/обратная продажа и мобильный поповер в браузере. Подсказки маршрута получают актуальную цену/время из профиля, завершённые цели сохраняются. Итоги и ограничения расчётных 2–3 недель: [отчёт](../../operations/world-pacing-market-2026-11-06.md). Production не публиковался.
