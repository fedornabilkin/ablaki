# Локальная копия тестовой БД

Цель: независимая локальная PostgreSQL с данными test для API и админки.
Контекст: локальные сервисы сейчас подключены к удалённой тестовой PostgreSQL; источник читается без миграций и изменений данных.

## Группа A: Копирование
- [x] A1. Подготовить совместимую локальную PostgreSQL, ограниченную 127.0.0.1.
- [x] A2. Получить согласованный дамп test и восстановить в новой локальной БД.
- [x] A3. Проверить структуру, количество записей и последовательности.

## Группа B: Подключение
- [x] B1. Переключить локальные API и админку, использовать новые пустые runtime-каталоги для локального кэша. Старые runtime сохранены, кэш схемы локальной БД выключен.
- [x] B2. Проверить вход, мир и админку; сохранить инструкцию запуска и результаты.

Критерии готовности: локальные сервисы используют локальную копию, источник test сохранён, повторный запуск описан, секреты и дамп находятся вне Git.

## Результаты

2026-10-06: portable PostgreSQL 11.21 запущена на `127.0.0.1:55432`, база `ablaki_local`, кодировка UTF-8. Согласованный custom-format дамп тестовой PostgreSQL 11.16 получен из экспортированного REPEATABLE READ / READ ONLY snapshot; источник не изменялся. Архив размером 3239213 байт и исходные контрольные суммы сохранены в `temp/local-database` вне Git.

До входов в локальные сервисы совпали контрольные суммы и количество строк всех 225 таблиц: 285610 записей. Совпал состав объектов схемы, перенесены 6 представлений. Проверены 149 последовательностей; исходный `craft_meta_id_seq` отставал от записи и был исправлен только в локальной копии. Отчёты: `verification.json`, `source-manifest.json`, `sequence-fix.json`; восстановление выполнено одной транзакцией без сохранения удалённых владельцев и ACL.

API 3180 и админка 3195 переключены через игнорируемый `temp/local-backend/settings.php`; frontend 5173 продолжает обращаться к локальному API через Vite proxy. Секреты отдельной локальной учётной записи находятся в `credentials.json`; `back/.env` и штатные настройки исходного backend не изменялись. Консоль локальной БД доступна через `temp/local-database/yii.ps1`, SQL — через `psql.ps1`.

HTTP smoke: вход Test01 через frontend proxy, карта мира, страница входа админки и 11 assets — HTTP 200. Headless Chrome: редактор шаблонов, автоматический уровень, сохранность дополнительных JSON-параметров, поиск владельца и проверка доступа, свободные/занятые ячейки, ссылки на карточки, хлебные крошки, финансы, плитки строительства и мобильный экран — PASS. `yii.ps1 migrate/history 5` прочитал историю импортированных миграций. Штатная остановка и повторный запуск PostgreSQL прошли; данные и подключение сохранились. PHP lint пройден для локальных помощников и настроек.

Инструкции: `temp/local-database/README.txt`, `temp/local-backend/README.txt`. Скрипты запуска API и админки запускают локальную PostgreSQL при необходимости. Windows-служба и автоматическая синхронизация с test не добавлялись.
