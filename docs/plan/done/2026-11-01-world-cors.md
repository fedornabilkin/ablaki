# Восстановление команд мира на production

Причина: браузер отправляет `Idempotency-Key` для безопасных повторов команд,
но nginx разрешал только `Content-Type, Authorization`. OPTIONS возвращал 204,
однако браузер блокировал следующий POST.

## Группа A: Исправление и защита от повторения

- [x] A1. Подтвердить отсутствующий заголовок через публичный HTTPS и прямой API.
- [x] A2. Разрешить `Idempotency-Key`, сохранив существующую политику CORS.
- [x] A3. Добавить проверку настоящего nginx для preflight команд мира и ошибок.
- [x] A4. Предусмотреть мягкую перезагрузку nginx для выпуска без изменений приложения: сохранить Compose оператора, не запускать миграции и не останавливать игровые операции.

## Группа B: Проверка и выпуск

- [x] B1. Пройти локальные проверки deploy и полный CI перед production.
- [x] B2. Выпустить проверенный SHA через GitHub Actions и подтвердить CORS публичного API.
- [x] B3. Устранить выявленные CI зависимости тестов от перехода секунды: учесть фактически прошедшее время паузы и сравнивать снимки квоты на один момент времени. Игровой код не меняется.

Критерий готовности: OPTIONS разрешает все три заголовка без дублирования
Allow-Origin, авторизация сохраняется, сервер доступен. Игровые тесты на production-БД не выполняются.
