# Размещение, строительство и удобство мира

Цель: размещение в выбранной ячейке с проверкой ресурсов, понятное строительство и стабильные формы админки.
Контекст: локальные сервисы используют независимую PostgreSQL `ablaki_local`. Пользователь выбрал скорость времени мира 1:60 с корректировкой в админке.

## Группа A: Фронт и размещение
- [x] A1. Font Awesome и поповеры; понятная профессия исследователя; имя родителя в навигации.
- [x] A2. Восстановить мини-карту выбранного объекта с его фактическим числом занимаемых ячеек.
- [x] A3. Разрешать плитки только для свободной выбранной ячейки и достаточных ресурсов; создавать объект в ней, затем редактировать имя и бюджет.
- [x] A4. Иконки строительства и запрет перехода на другие карты до остановки работы.
- [x] A5. Станции размещаются внутри подходящих дочерних помещений и мест; сервер проверяет это правило.
- [x] A6. Ежедневное сырьё собирается только на стоянке; таймер после сбора; восстановить обработку ночей локально.

## Группа B: Админка
- [x] B1. Исправить ложное изменение фиксированных ID при выборе координат.
- [x] B2. Сохранение сворачивания меню и настоящее дерево родителей шаблона.
- [x] B3. Время мира 1:60, редактируемый коэффициент и трудоёмкость в единицах мира.
- [x] B4. Ссылки на родителя и дочерние объекты в карточке ноды.

## Группа C: Проверка
- [x] C1. Серверные проверки требований, координат, размещения станций и бюджета; PHP lint.
- [x] C2. Frontend tests/build и браузерные сценарии на локальной БД; документация API и Insomnia.

Критерии готовности: сценарии выполнены, проверки зафиксированы, все локальные сервисы работают; тестовая и production БД не изменяются.


## Результаты проверки 2026-10-06

- PHP 7.3 parser и runtime lint: 53 файла без ошибок.
- Frontend: 46 файлов, 261 тест; production-сборка успешна.
- PostgreSQL ablaki_local: 24 проверки координат, требований, имени/бюджета, времени 1:60 и редактирования коэффициента, размещения станций, снабжения и обработки ночей. Игровые мутации теста откатились транзакцией.
- На отдельной восстановленной PostgreSQL ablaki_world_flow_checks шесть параллельных запросов с общим ключом создали ровно один объект; шесть разных ключей к одной ячейке создали один объект и вернули пять MAP_CELL_OCCUPIED. Исходная локальная база в этом тесте не менялась.
- Регрессии world-admin-entities, world-forum80 и classic-craft прошли.
- Браузер с реальным API: админка, древовидные родители, ссылки, координаты, сохранение бокового меню, страницы коэффициента/трудоёмкости, карта, исследование, бюджет и мобильная вёрстка.
- Браузер с контролируемыми ответами API: доступность плиток по выбранной ячейке/ресурсам, немедленное размещение, сохранение диалога при обновлении карты, имя/бюджет, точная мини-карта, молоточки, дневной таймер, восстановление работы после перезагрузки и переход после подтверждённой остановки.
- API-контракт, архитектура, инструкция оператора, frontend-документ и Insomnia обновлены. Проверки и логи вне Git: temp/world-placement-flow/.

Локальная миграция внутренних карт/слотов применена. Обработчик мира запущен и включён в локальный start-api.ps1; очередь ночей пользователя обработана. PostgreSQL 55432, API 3180, админка 3195 и frontend 5173 отвечают. Коэффициент меняется в /world/node/update?id=1. Выкладка этой пачки на удалённые базы не выполнялась.
