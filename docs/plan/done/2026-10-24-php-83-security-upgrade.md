# Обновление PHP до 8.3.36

Цель: перейти с PHP 7.3.2 на исправленный PHP 8.3.36 отдельным выпуском от production-кода, обновить несовместимые и уязвимые зависимости, проверить приложение и фактический runtime.

## Группа A: Код и окружение

- [x] A1. Закрепить PHP 8.3.36 для FPM, Composer и CI; обновить сборку GD и отключить session upload progress до следующего исправления PHP.
- [x] A2. Обновить Yii и остальные зависимости с текущими security advisories, привести тестовые зависимости к PHP 8.3, согласовать composer.json и lock.
- [x] A3. Подготовить проверяемую смену PHP-образа и vendor без изменения БД, .env и незавершённых игровых операций; предусмотреть проверку версии и возврат предыдущего образа.

## Группа B: Проверки

- [x] B1. Проверить установку production/dev из lock, Composer audit, синтаксис и имеющиеся серверные сценарии.
- [x] B2. Пройти проверки транзакций и конкуренции на MySQL/PostgreSQL с PHP 8.3.36.
- [x] B3. Собрать Linux FPM/Composer-образы и проверить HTTP, расширения, конфигурацию сессий и остановку процессов в CI.

## Группа C: Выпуск

- [x] C1. Опубликовать рабочую ветку и проверить новый runtime на test с сохранением данных.
- [x] C2. Выпустить проверенную рабочую ветку в production по GitLab Flow и подтвердить PHP 8.3.36, вход, API и фоновые процессы.
- [x] C3. Сохранить версии, результаты, ограничения и инструкцию отката; синхронизировать рабочую ветку мира с обновлением runtime.

Критерий готовности: фактический runtime 8.3.36, совместимые зависимости и успешные проверки без переноса невыпущенных изменений мира в production. Обновление БД и игровые сбросы в пакет не входят.

Локальная проверка 2026-10-24: PHP 8.3.36; 607 PHP-файлов production-кода без синтаксических ошибок; 15 изолированных API-сценариев, target-database/classic-craft/user-activity на MySQL и PostgreSQL пройдены. Composer audit для полного lock не обнаружил advisories. Проверены холодный/повторный запуск, ошибка сборки до остановки, ошибка подготовки vendor без остановки, откат после ошибки старта и dev/no-dev policy. Локальные API/админка/worker переведены на новую версию без изменения БД; дополнительные world-feedback-food, world-economy-gameplay и world-economy-profile пройдены.

Выпуск завершён 2026-10-24. Production e44b1c2: PHP 8.3.36, Yii 2.0.55, FPM ready, session upload progress отключён, cron работает, platform requirements пройдены. Test 8a4eed1: те же версии и проверки; отдельный worker явно вернул PHP 8.3.36. API local/test/production — HTTP 200; вход и профиль тестового аккаунта local/test — HTTP 200. В production проверены ответы 401 на защищённый профиль и пустую форму входа, без использования пароля реального аккаунта. БД не сбрасывалась и не копировалась. Прежние образ/vendor оставлены для отката, PHP-ветка удалена после merge, feature/09-worlds синхронизирована с master.
