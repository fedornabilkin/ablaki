# Мир: задачи темы 82 и чистый локальный процесс

## Цель и контекст

Поручение владельца 2026-10-23: очистить локальный игровой процесс и выполнить все задачи [темы 82](http://94.250.251.94:3181/forum/read/82). Прочитаны сообщения 285, 287–298, 300 (14 сообщений). Более поздние 297/300 уточняют сбор и стартовые средства. Локальная БД остаётся прежней; пользователи, авторизация, личные кошельки и неигровые разделы сохраняются. Бюджеты владелец пополняет сам; новая эмиссия и ручное дублирование стартовых переводов не нужны.

## Группа A: Сброс и основание

- [x] A1. Сохранить текущий локальный архив, очистить только игровой домен и сверить сохранность неигровых таблиц после установки.
- [x] A2. Сортировать темы форума/главной по последнему сообщению убыванием (285).

## Группа B: Стартовые средства и расчёты

- [x] B1. При первом размещении стоянки направлять стартовое финансирование из бюджета родителя в бюджет стоянки; при недостатке создавать обязательство и погашать FIFO при поступлении средств (290, 300).
- [x] B2. Показать отсутствие стартового обеспечения до вступления, предложить другое поселение; убрать непонятные действия организатора из пользовательских заданий (290).
- [x] B3. Вскопка владельцем бесплатна; бюджет огорода позволяет оплатить чужую работу (287).
- [x] B4. После пополнения показать результат вместо расчёта, обновить интерфейс; скрывать недоступные счета, обновление и вкладку вещей (291).

## Группа C: Оплачиваемая шахта

- [x] C1. Дать владельцу настройку допуска работников и цены партии; проверять активность, прочность ≥50%, собственный склад/место и свободный бюджет (292).
- [x] C2. Дать другому игроку с HP ≥60 добывать на склад объекта и получать оплату каждой партии, с резервированием, идемпотентностью и защитой от конкуренции (292).

## Группа D: Строительство и начало пути

- [x] D1. Ввести минимальный бюджет строительства пропорционально прочности, лимит помощников из бюджета (2 кредита на одного); обновить настройки и пояснения (295).
- [x] D2. Усилить стоянку/родительские уровни и открывать при завершении только начальную ячейку, оставляя исследование игроку (296).
- [x] D3. В начале страницы разместить старт с 5–7 шагами, объяснить сбор до постройки добычи; открыть все допустимые объекты для теста, включая мини-склад (294, 300).

## Группа E: Интерфейс мира

- [x] E1. Задания — иконка; сбор — компактная кнопка «Собрать» с рукой/бликом и модалкой с предметами, количествами и лимитом; после сбора только галочка/таймер; исправить недоступный сбор (288, 297).
- [x] E2. Статусы ноды — иконки без счётчика объектов; мир — глобус; ночлег — отдельная метка (289, 293, 300).

## Критерии готовности

Все 14 сообщений покрыты проверяемыми изменениями. Стартовые и трудовые выплаты происходят только из существующих бюджетов, сохраняются при повторе команды и не превышают резервы. Чистый локальный мир готов владельцу; внешние публикации/сообщения форума выполняются только в отдельно разрешённом объёме.
