# Отмена новой стройки с частичным возвратом

Цель: убрать отменённый объект с карты и применять потерю 30% материалов независимо от прогресса.

Контекст: прямое поручение владельца от 2026-10-12; без миграций и изменений ремонта.

## Группа A: Сервер

- [x] A1. Возвращать `floor(quantity * 0.7)` каждого материала внутри существующей транзакции команды.
- [x] A2. После архивации повысить revision родителя для обновления дерева клиента.
- [x] A3. Вернуть `return_node_id` родителя только для отмены новой стройки.
- [x] A4. Обновить контракт и описание запроса Insomnia.

## Группа B: Проверки

- [x] B1. Проверить отмену при нулевом и ненулевом прогрессе, освобождение позиции, видимость и идемпотентный повтор в `ablaki_world_reset_checks` с откатом.
- [x] B2. Проверить прежние сценарии ремонта и lint трёх PHP-файлов.

Критерии готовности: карта исключает архивный объект, повтор не дублирует возврат, ремонт сохраняет объект. Артефакты: `temp/world-build-cancel/` в общей рабочей папке.
