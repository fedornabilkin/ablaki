# Резерв заселения и управление строительством

По поручению 2026-10-23: выделить защищённый стартовый резерв и ставку новому поселенцу, показать доступность до вступления, исправить расчёты строительного бюджета и завершить изменения интерфейса. Локальный прогресс сохраняется; новая эмиссия не производится.

## Группа A: Заселение

- [x] A1. Хранить настройку выплаты и защищённый резерв из бюджета поселения; дать управление в админке и API с аудитом и идемпотентностью.
- [x] A2. Выплачивать старт из резерва, сохраняя принятые обязательства и очередь; считать доступные места по городу и региону.
- [x] A3. Показать доступность средств до вступления и финансовую сводку резерва в админке.

## Группа B: Строительство и расчёты

- [x] B1. Разрешить нулевой бюджет для самостоятельной стройки, нормализовать пустой ввод, проверять доплату и изменение бюджета помощников без потери их оплаты.
- [x] B2. Дать запуск, паузу и прогресс дочерней стройки с карты родителя.
- [x] B3. После целевого перевода показать результат и убрать подтверждённый расчёт; раскрыть правила казны.

## Группа C: Интерфейс и проверка

- [x] C2. Пометить исследуемые ячейки; показать счётчик оставшихся шагов заданий.

## Подтверждение

PHP 7.3 lint пройден. На SQLite проверены очередь, принятые суммы, резерв, уменьшение и увеличение бюджета строителей, отсутствие/наличие личной доплаты и повтор команды. На PostgreSQL/MySQL пройдены `world-feedback-food`, недельный `world-economy-gameplay` и `world-economy-race`; новый сценарий шести параллельных пополнений даёт ровно три обеспеченных места, повтор изменения ставки — одну операцию. Повтор миграции сохраняет настройки и деньги. Схема 42 установлена локально без сброса прогресса. Контракт и Insomnia обновлены.

Клиент: 374 теста (55 файлов) и production-сборка проходят. В Chrome на LocalMvp01 и LocalMvp02 проверены город/регион, запрет чужого управления резервом, бейдж, мобильная ширина и неизменный верх модалок при смене вкладок/выдаче сырья. Админская форма проверена с CSRF и серверной валидацией. UI сбора проверялся с изолированным ID и ответом, без изменения игрового инвентаря. Варианты нулевого/положительного бюджета и работа с картой родителя проверены поведенческими тестами. Логи и снимки — `temp/settlement-reserve` вне Git.
