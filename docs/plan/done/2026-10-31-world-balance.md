# Комфортное развитие без внешних пополнений

Цель: ускорить базовый путь нового жителя и сохранить дорогие полезные цели, затем пройти всё дерево новым обычным игроком. Исходная проверка: 182 дня, 129 ч добычи/работы, 28 ч стройки; на финише исчерпывался свободный фонд NPC.

Подтверждённый владельцем ориентир: основные возможности за 3–5 игровых дней, полное дерево за 14–21 день. Цены и принятые условия уже начатых операций не пересчитывать задним числом. Частные счета и защищённые обязательства не использовать для пополнения NPC.

## Группа A: Правила и полезные цели

- [x] A1. Рассчитать и опубликовать согласованный профиль цен, материалов, длительности работ и зарплат.
- [x] A2. Направлять свободный фонд NPC прежде всего на оплачиваемую работу; возвращать публичные отчисления в оборот без выпуска денег.
- [x] A3. Оставить дорогие дом, буровую и улучшения хозяйства с проверяемыми преимуществами.
- [x] A4. Обновить задания и описания, показывающие, зачем нужны следующие кредиты и материалы.

## Группа B: Полное повторное прохождение

- [x] B1. Зарегистрировать нового игрока на отдельной PostgreSQL-копии локального мира.
- [x] B2. Пройти все этапы настоящими командами без внешних пополнений и административных игровых прав; ускорять только ожидание.
- [x] B3. Проверить преимущества дорогих объектов, сохранность квот, принятых условий и денег.
- [x] B4. Выполнить регрессии, сравнить сроки/активное время, обновить документацию и применить профиль локально.

Готовность: все шаги и типы объектов завершены, нет ожидания ежедневного кредита из-за пустого фонда NPC, приведены фактические сроки и ограничения проверки.
