# Интерфейс мира и администрирование

Цель: удобная навигация и размещение на фронте; читаемые связи и формы в админке.
Контекст: локальные frontend/backend подключены к общей тестовой БД; проверки не изменяют её данные.

## Группа A: Мир на фронте
- [x] A1. Хлебные крошки начинаются с названия мира, шапка содержит бюджет и казну, описание находится под названием.
- [x] A2. Одна доступная кнопка исследования автоматически выбирает эликсир при недостаточном уровне. Совместимые представления схемы уже обеспечивают чтение общей таблицы нод; изменение серверного исследования не потребовалось.
- [x] A3. Убрать рамки фокуса мышью, сохранить клавиатурную навигацию; разместить плитки доступных шаблонов под картой.

## Группа B: Общая админка
- [x] B1. Названия и связанные сущности ведут на просмотр; владельцы отображаются логинами.
- [x] B2. Малые списки — радиокнопки; связанные ID — поиск; формы адаптивно размещены в 2–3 колонки.
- [x] B3. Редактор шаблона: тип, иерархия родителей, автоматический уровень, таблица требований и настройки с JSON-представлением.
- [x] B4. Редактор ноды: выбор свободных координат, серверная проверка занятости.

## Группа C: Проверка
- [x] C1. PHP lint и проверки изменённого поведения на изолированной БД; чтение локальной админки с тестовой БД.
- [x] C2. Frontend unit tests и production build; проверить сохранность выделения, перетаскивания и команд.

Критерии готовности: все пункты выполнены; изменения доступны в локальных сервисах; проверки и ограничения зафиксированы.

## Результаты проверки

2026-10-06: 259 frontend-тестов в 46 файлах и production build прошли. Сохранены проверки выделения нескольких объектов, перетаскивания и команд; добавлены сценарии исследования с уровнем, эликсиром и без обоих ресурсов. PHP lint прошёл для всех 30 изменённых/новых PHP-файлов, включая ранее исправленные формы каталога предметов.

Изолированный SQLite fixture `world-admin-entities.php` и дополнительные проверки в `temp/world-ui-admin/behavior.php` подтвердили автоматический уровень, запрет смешанных и некорректных родителей, типы требований, сохранение инвентаря при проверке инструментов, свободные/занятые/внешние координаты и отображение связей. Новые схемы и механизмы блокировок не вводились; проверки SQLite не объявляются проверкой параллельных транзакций PostgreSQL.

Headless Chrome с реальными локальными сервисами и тестовой PostgreSQL проверил хлебные крошки, шапку, плитки с предвыбранным шаблоном, редакторы шаблона и ноды, поиск владельца, ссылки на карточки, автоматический уровень, блокировку занятых ячеек, компактные формы и мобильную ширину 390px без горизонтального переполнения. Поиск произвольной таблицы возвращает 404, гостю — 403. Списки комментариев и карточка темы также возвращают HTTP 200. Сохранения административных форм и игровые команды на общей тестовой БД не выполнялись; вход использовал обычный механизм авторизации.

Артефакты и снимки экрана находятся вне Git в `temp/world-ui-admin`. API 3180, админка 3195 и frontend 5173 продолжают работать локально. Для соединения с удалённой тестовой БД локальный кэш схемы включён на час, dev-таймаут frontend увеличен до 60 секунд; production сохраняет 15 секунд. Инструкция запуска и очистки локального кэша обновлена в `temp/local-backend/README.txt`.
