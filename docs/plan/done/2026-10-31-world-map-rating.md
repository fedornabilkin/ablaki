# Ячейки карты и рейтинг мира

Цель: осмысленная цена расширения без внешних пополнений и убывающие награды рейтинга за завершённые действия.

Контекст: первое кольцо 0,5 Cr, второе 10 Cr; игры делят половину ставки на текущий рейтинг с поправкой внизу шкалы. Сохраняем купленные права, опубликованные версии и атомарность операций.

## Группа A: Экономика карты
- [x] A1. Пересчитать кольца и проверить стоимость маршрута развития.
- [x] A2. Для исследования внешних ячеек требовать купленные соседние ячейки; согласовать клиент и сервер.
- [x] A3. Опубликовать новую версию цен локально, сохранив остальные настройки.

## Группа B: Рейтинг
- [x] B1. Выделить чистую формулу с уменьшением награды по рейтингу и числу повторов.
- [x] B2. Атомарно начислять рейтинг за исследование, покупку, завершённую стройку и партии крафта, записывать историю и защищать повтор.
- [x] B3. Проверить откат, повторы, пакетные операции и конкуренцию.

## Группа C: Проверки и описание
- [x] C1. Прогнать затронутые проверки и собрать фронтенд.
- [x] C2. Зафиксировать формулу, цены и результаты проверки маршрута.

Готовность: цена совпадает в расчёте и списании; каждая завершённая операция награждается один раз; число партий учитывается независимо от разбиения запросов; деньги не создаются рейтингом.

Результат: [расчёт](../../architecture/world-map-rating.md) и [проверка](../../operations/world-map-rating-2026-10-31.md). Пять новых игроков прошли по 55/55 шагов за 19,482 суток с тестовыми часами; общий денежный итог сошёлся. Локально опубликован профиль v5. Полный CI конкретного production-выпуска остаётся в плане запуска.
