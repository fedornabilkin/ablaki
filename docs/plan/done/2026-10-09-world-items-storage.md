## Результат и проверки

Экспорт `docs/temp/world/1.json`: 20 объектов с картами, параметрами и строительством; 23 доступных шаблона; 53 определения предметов с рецептами; 40 записей вещей мира и рюкзаков его участников. Журналы, команды, пользователи и прочие таблицы не экспортируются. Прежний полный снимок сохранён вне Git в `../temp/world-items/previous-1.json`.

Миграция отключения сундука проверена на `ablaki_world_reset_checks` и применена к локальной `ablaki_local`; объекты и инвентарь сохранены. Новые установки получают сундук только из крафта; существующие ссылки на исторический шаблон сохранены. Архивные шаблоны скрыты из обычного списка, доступны через явный фильтр.

- Фронтенд: 289/289 unit-проверок, `npm run build` выполнен.
- PHP: 119/119 файлов проверены runtime lint и парсером PHP 7.3.
- PostgreSQL: 26 проверок предметов/хранилищ, 68 проверок общей основы. Поведенческие проверки используют внешнюю транзакцию с откатом на отдельной БД.
- SQLite: 452 проверки миграций, прежних сценариев и CRUD. Миграция сундука применяется после перехода со старой схемы.
- Chrome: реальные иконки, названия, характеристики кровати/костра/сундука, кнопка возврата; оптимистичный перенос, откат, сохранение DOM ячеек, отсутствие перезагрузки документа; мобильный интерфейс 390px; точность неизменённых денежных полей FormData в админке. Изменяющие API-запросы браузерной проверки перехвачены; основной локальный мир не менялся.
- JSON экспорта и коллекции Insomnia валидны; описание API обновлено.

Локальные фронт 5173, API 3180, админка 3195 и PostgreSQL 55432 оставлены запущенными.
