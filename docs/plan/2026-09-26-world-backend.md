## Цель и контекст

Построить серверный мир на существующей игре Yii2: сохранять каталог/инвентари/Cr/ремесленный опыт, размещать станции и сундуки в зданиях, добавить производство, NPC, профессии, события и квесты. Источник: [world.md](../tz/world.md); решения и расхождения: [архитектура](../world-architecture.md); [API](../world-api.md). Зависимости: [DB](2026-09-26-world-database.md), [FE](../../../frontend/docs/plan/2026-09-26-world-frontend.md).

Задачи обозначаются `BE:A1` и т. п. Реализация идёт вертикальными срезами S0–S3; дальнейшие направления — группа J. Приоритет имеют работающие механики и публичные контракты, а не повторное выполнение старых планов `craft.md`/`mvp-ablaki-craft.md`. Новые сервисы PHP 7.3, текущая структура Yii2, PostgreSQL/MySQL; никакой обязательной смены framework, auth или UI-библиотеки.

Уточнение владельца: [старт, ночлег, бюджеты/казна и расширения](../world-gameplay-economy.md). Группы K–M входят в S1/S2, несмотря на добавление в конец плана; ранние E1/F1–F2 переносятся в S1. Сбор = казна→свой бюджет; выплата наверх = бюджет→казна родителя. Несобранная казна подвержена разграблению; пассивного автосбора нет.

## Проверочная матрица

| Сценарий | Ожидаемый результат |
|---|---|
| Два клиента ставят один сундук/два предмета в один слот | Один успех, один 409; сумма вещей и содержимое неизменны. |
| Станция снята/сломана между preview и craft | Commit пересчитывает доступность, не списывает материалы по устаревшему preview. |
| Ручной repair одновременно с NPC production | Один экземпляр не используется сверх правил; резервы/износ не потеряны. |
| Lease рюкзака истёк, сундук размещён/полон | Overflow сохранён; размещённый сундук не исчезает; снятие требует место. |
| Снос/архивирование дома с сундуком и NPC | Понятный запрет либо административный recovery, никаких cascade потерь. |
| Два worker/двойная доставка/сбой после commit | Один tick-result, один XP award, одна награда/проводка. |
| Изменение контента во время производства | Принятый order использует свою revision; новые заказы видят новую. |
| Повтор старого craft request_key после миграции | Тот же результат, без нового расхода/выдачи; новые данные storage не меняют fingerprint. |
| Повтор install/uninstall одного предмета | Нет бесконечного XP и восстановления прочности. |
| Изменённые данные localStorage | Не создают город, предметы, опыт или Cr на сервере. |

S2: E–F и M4–M5, производство/урожай и деньги согласованы после простоя. S3: G–H и вся матрица §29 ТЗ. J — самостоятельная дорожная карта после MVP.
