- **Последний прикладной релиз — 3 ноября.** Backend `d6d6f96`, frontend `af177ee`; [два явных полива](done/2026-11-03-cultivation-stages.md), полный CI и подтверждённая production-публикация. Последующие `25876e8`/`255e2e4` меняли только документацию.
- **Исправления после запуска:** [CORS](done/2026-11-01-world-cors.md), [рейтинг и крафт](done/2026-11-01-world-rating-craft.md), [переносы в склад](done/2026-11-01-warehouse-transfer.md).
