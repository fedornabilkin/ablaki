# Планы backend

Актуально на 2026-10-29. Выполненные пакеты находятся в [done](done/); удалённые отменённые планы не являются очередью. Связанные ручные проверки перенесены с явным указанием источника и остаются открытыми.

## Ближайшая работа

1. [Запуск MVP](2026-10-21-mvp-launch-readiness.md): владелец проходит двумя пользователями свежий локальный мир и сохраняет результаты чеклиста; затем отдельно готовится production.
2. [Приёмка ACC](2026-10-15-world-closed-test-acceptance.md): деньги/предметы, права, повторы, лимиты, полный склад, работа и визуальная матрица.
3. [Выкладка до двух минут](2026-10-19-test-deployment-optimization.md): короткий путь уже внедрён; остаются общий хронометраж, устранение пауз и серия десяти выпусков.
4. [Денежное продолжение BAL:B3/B4](2026-10-15-world-economy-balance.md): конечные NPC-средства и заказы не гарантируют постоянный заработок для открытого мира.

Общая очередность и зависимости: [закрытый тест](2026-10-15-world-closed-test.md). Локальная подготовка завершена: [сброс 29 октября](done/2026-10-29-local-world-reset.md). Чеклист установлен локально; test/production этим сбросом не менялись.

## Завершённое и отменённое

В done перенесены аудит веток, восстановление деплоя, форумный серверный пакет, классический крафт, ECO, CONTENT и быстрые test-gates. Ручные проверки прежних UI-пакетов собраны в [едином QA-плане](../../../frontend/docs/plan/2026-10-29-manual-ui-acceptance.md).

Удалены отменённые банк/офферы, промежуточные схемы deployment и старый проект повторного создания craft API. Исходное расширенное ТЗ крафта сохранено в [tz](../tz/mvp-ablaki-craft.md). История изменений доступна в Git. [Результат актуализации](done/2026-10-29-plan-refresh.md).
