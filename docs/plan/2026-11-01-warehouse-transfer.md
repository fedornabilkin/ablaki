# Проверка хозсклада

Цель: подтвердить сохранность вещей при освобождении переполненного рюкзака через существующий API переноса. Ошибка обнаружена в выборе и показе хранилища на frontend; серверный алгоритм не меняется.

## Группа A: Проверки
- [x] A1. Добавить сценарий настоящего хозсклада на временной БД: полный рюкзак, предмет сверх лимита, перенос туда и обратно, повтор команды, занятая ячейка и чужой владелец.
- [x] A2. Выполнить сценарий на временной SQLite; включить его в цепочку world-rating.php, которую CI запускает на MySQL/PostgreSQL/MariaDB.
- [ ] A3. Подтвердить результат CI без выкладки backend.

Готовность: одинаковое количество вещей до и после успешных/отклонённых операций; production-БД для тестов не используется.
