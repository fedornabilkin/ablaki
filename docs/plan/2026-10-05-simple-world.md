# Простой мир

Цель: семь уровней объектов, расширяемые шаблоны, строительство с учётом труда,
единый каталог предметов и обычные Yii CRUD вместо отдельных систем для каждого типа объекта.

Контекст: работа в существующей `feature/09-worlds`; чужие незакоммиченные изменения сохраняются.
Исторические таблицы и оплаченные права не удаляются. Изменения готовятся локально, без выкладки.

## Группа A: Структура
- [ ] A1. Вложить крафт в world, собрать связанные подсистемы и маршруты в модуле.
- [ ] A2. Разделить API по предметным областям, сохранить адреса существующих чтений.
- [ ] A3. Перенести работу с данными в модели.

## Группа B: Модель
- [ ] B1. Ввести ActiveRecord объектов и шаблонов, семь уровней и допустимые связи шаблонов.
- [ ] B2. Подготовить повторяемую миграцию существующих объектов без удаления данных.
- [ ] B3. Реализовать стройку, серверный учёт времени и оплату помощников из бюджета родителя.
- [ ] B4. Обеспечить стартовый набор и воспроизводимый seed: мир, два региона, четыре города, шахта.
- [ ] B5. Представить события и финансы отдельными моделями.

## Группа C: Интерфейсы
- [ ] C1. Добавить CRUD объектов, шаблонов и событий с GridView, ActiveForm, DetailView, поиском и сортировкой.
- [ ] C2. Согласовать API и пользовательский вход в упрощённый мир.
- [ ] C3. Обновить контракт API и инструкции установки.

## Группа D: Проверки
- [ ] D1. Проверить иерархию, шаблоны, старт, строительство, повторы, права и откат оплаты.
- [ ] D2. Выполнить PHP lint, регрессионные проверки маршрутов и доступные проверки СУБД.

Критерии готовности: нет обхода шаблонов или создания готовых пользовательских объектов;
деньги и материалы сохраняются при повторе и ошибке; все новые разделы доступны из админки;
ограничения проверок описаны явно.
