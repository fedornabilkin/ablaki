# Минимальные проверки перед test и полный прогон после публикации

Поручение 2026-10-26: новая версия должна становиться доступной на тестовом стенде после коротких необходимых проверок; остальные тесты запускаются после публикации. Цель — оперативные исправления без ручных пауз. Полные проверки production остаются обязательными до его выкладки.

## Группа A: Проверки

- [x] A1. Оставить перед test backend синтаксис, lock/platform и короткие сценарии запуска/авторизации/основных операций; исключить запуск сервисов MySQL/PostgreSQL из минимального job.
- [x] A2. Выполнять полные backend/MySQL/PostgreSQL проверки отдельным job после успешного test deploy; сохранить блокировку production полным прогоном.
- [x] A3. Для test frontend оставить проверки транспорта/авторизации, окружения и сборку; полный клиентский прогон выполнять после публикации.

## Группа B: Публикация

- [x] B1. Повторно использовать установленный мир при совпадении установочных файлов и подтверждённом состоянии БД; при pending/изменениях сохранять полный возобновляемый путь.
- [x] B2. Встроить публикацию изменённого профиля в выпуск с проверкой автора и сохранности средств/вещей; сохранить изменения профиля администратора при неизменённом файле.
- [x] B3. Исправить завершение worker после текущей работы и переиспользовать SSH и передавать только изменённые файлы frontend с полным манифестом.
- [x] B4. Подтверждать готовность коротким автоматическим smoke и точной версией; результат deploy доступен до окончания дополнительных тестов.

## Группа C: Проверка внедрения

- [x] C1. Проверить отказ коротких проверок, готовый/неготовый мир, повтор, профиль и завершение worker изолированными сценариями.
- [x] C2. Опубликовать изменения в test обоих репозиториев; измерить запуск минимального пути, повторную выкладку и независимый полный прогон.
- [x] C3. Обновить инструкции и фактические измерения. Не считать максимум 120 секунд доказанным без серии измерений из общего плана оптимизации.

Результат и фактические замеры: [отчёт](../operations/fast-test-release-2026-10-26.md). Общий критерий десяти выпусков E1/E2 остаётся открытым; этот пакет закрывает минимальные gates и проверенный короткий путь.
