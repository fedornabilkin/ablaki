# Системная скидка на пакет улучшений

Для системных покупок расширений огорода и мест оборудования сервер применяет скидку 5%, если в одной команде приобретаются три или более места. Покупки у владельцев, включая предложения помещений и поселковые заказы, это правило не используют.

`ExpansionPolicy` сначала считает исходную прогрессивную стоимость, затем вычисляет скидку точной арифметикой `Money::portion`. Остаток дробных долей переносится между позициями, поэтому сумма отображаемых цен каждой грядки/места совпадает с суммой к списанию. Quote содержит `gross_total`, `discount_bps`, `discount_amount`, итоговый `total` и цены позиций после скидки. Те же данные входят в подписанную серверную котировку, проверяются повторно при подтверждении и сохраняются в правах на купленные позиции.

Миграция не нужна. Настройка процента администратором не добавлена: текущая ставка 5% задана общим правилом игры. Клиент только отображает серверный расчёт и не рассчитывает стоимость самостоятельно.
