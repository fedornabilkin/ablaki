# Инструкция: приоритизация и план внедрения авторизации «Аблакин»

**Версия:** 1.0  
**Дата:** 30.10.2026  
**Назначение:** сформировать атомарный план реализации авторизации и регистрации.  
**Принцип:** сначала минимальный безопасный вход, затем дополнительные провайдеры, потом антифрод и улучшения.

---

# 1. Цель

Создать систему регистрации и авторизации, которая:

- позволяет пользователю быстро начать играть;
- не требует сложной регистрации на старте;
- не создаёт дубликаты аккаунтов;
- защищает от базовых атак и ботов;
- работает бесплатно или почти бесплатно;
- поддерживает Telegram, VK ID, Яндекс ID и email;
- легко расширяется в будущем.

---

# 2. Приоритеты

## Приоритет 1. Telegram Mini App

**Почему первым:**

```text
Бесплатная авторизация
Быстрый вход
Не нужен пароль
Не нужен SMS-провайдер
Удобно для мобильных пользователей
Можно отправлять уведомления через бота
Хорошо подходит для игры
```

**Что реализуем:**

```text
Telegram-бот
Mini App
Проверка initData на сервере
Создание пользователя
Собственная сессия или JWT
```

**Результат:**

```text
Пользователь открывает игру из Telegram
и сразу попадает в свой аккаунт.
```

## Приоритет 2. Email + магическая ссылка

**Почему вторым:**

```text
Универсальный способ входа
Не зависит от Telegram
Нужен для восстановления доступа
Нужен для пользователей без Telegram
Дёшево реализовать
```

**Что реализуем:**

```text
Ввод email
Отправка письма
Магическая ссылка
Подтверждение входа
Создание или поиск аккаунта
```

**Результат:**

```text
Пользователь может войти по email
без пароля.
```

## Приоритет 3. VK ID

**Почему третьим:**

```text
Большая русскоязычная аудитория
Один провайдер покрывает VK, OK и Mail.ru
Удобный OAuth-вход
Хорошо подходит для веб-версии
```

**Что реализуем:**

```text
Кнопка «Войти через VK ID»
OAuth-авторизация
Обмен кода на токены на бэкенде
Создание или поиск аккаунта
Связывание с существующим аккаунтом
```

**Результат:**

```text
Пользователь входит через VK ID
без создания пароля.
```

## Приоритет 4. Яндекс ID

**Почему четвёртым:**

```text
Дополнительный охват аудитории
Полезен для веб-трафика
Не является обязательным на старте
```

**Что реализуем:**

```text
Кнопка «Войти через Яндекс»
OAuth 2.0
Получение профиля
Создание или поиск аккаунта
Связывание с существующим аккаунтом
```

**Результат:**

```text
Пользователь входит через Яндекс ID.
```

## Приоритет 5. Антифрод и безопасность

**Почему пятым:**

```text
Базовую защиту нужно сделать сразу.
Сложный антифрод — после появления реальных атак.
```

**Что реализуем:**

```text
Rate limiting
Журнал авторизации
Блокировка подозрительных операций
Проверка устройств и IP
Ограничение попыток
Мониторинг аномалий
```

**Результат:**

```text
Система устойчива к базовому фроду и брутфорсу.
```
