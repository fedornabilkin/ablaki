# Техническое задание

## Стена пользователя и система приглашений сайта «Аблакин»

**Версия:** 1.1  
**Этап:** MVP  
**Назначение:** привлечение новых пользователей через публичную стену пользователя, публикации и персональный код приглашения.

---

# 1. Основное изменение

Вместо отдельной реферальной ссылки используется **стена пользователя**.

Каждый пользователь получает публичную страницу:

```text
/profile/{username}/wall
```

или:

```text
/u/{username}
```

Стена пользователя является одновременно:

- публичным профилем;
- страницей публикаций;
- персональной посадочной страницей;
- местом отображения достижений;
- источником приглашения новых пользователей;
- точкой привязки реферала.

Пользователь не обязан отправлять техническую реферальную ссылку.

Он может отправить ссылку на свою стену:

```text
[https://ablakin.example/u/alex](https://ablakin.example/u/alex)
```

После перехода новый пользователь видит:

- имя пригласившего;
- аватар;
- описание;
- достижения;
- публикации;
- рейтинг;
- созданные объекты мира;
- кнопку регистрации;
- условия бонуса.

При регистрации система автоматически определяет владельца стены как потенциального реферера.

---

# 2. Цели системы

Система должна:

- сделать приглашение естественной частью сайта;
- превратить стену пользователя в персональную страницу входа;
- позволить приглашать через публикации;
- сохранить простую двухуровневую структуру;
- начислять рефереру кредиты;
- увеличивать рейтинг реферера;
- выдавать стартовый бонус новому пользователю;
- ограничивать накрутку;
- не требовать от пользователя ручного копирования сложной реферальной ссылки;
- позволять делиться страницей стены через Telegram, Discord, социальные сети и обычную ссылку.

# 3. Термины

## 3.1. Стена пользователя

Публичная страница пользователя с публикациями, профилем и игровыми достижениями.

## 3.2. Владелец стены

Пользователь, которому принадлежит публичная страница.

## 3.3. Посетитель

Неавторизованный или авторизованный пользователь, открывший стену.

## 3.4. Приглашённый пользователь

Новый пользователь, который зарегистрировался после посещения стены другого пользователя и был привязан к её владельцу.

## 3.5. Реферер

Владелец стены, к которому привязан новый пользователь.

## 3.6. Реферальная связь

Связь между владельцем стены и зарегистрированным пользователем.

## 3.7. Уровень связи

Максимум два уровня:

```text
1-й уровень — пользователь зарегистрировался через стену напрямую
2-й уровень — пользователь зарегистрировался через стену реферала 1-го уровня
```

## 3.8. Кредиты

Внутренняя игровая валюта проекта.

## 3.9. Рейтинг

Показатель активности и качества приглашений пользователя.

# 4. Основная схема приглашения

```text
Пользователь A
└── Стена A
    └── Публикация A
        └── Посетитель B
            └── Регистрация B
                └── Реферальная связь A → B
```

Для второго уровня:

```text
Пользователь A
└── Пользователь B
    └── Стена B
        └── Пользователь C
            └── Реферальная связь B → C
                └── Косвенная связь A → C
```

Распределение награды:

```text
A получает награду за B как реферала 1-го уровня.

B получает награду за C как реферала 1-го уровня.

A получает уменьшенную награду за C как реферала 2-го уровня.
```

# 5. URL стены пользователя

## 5.1. Основной URL

```text
/u/{username}
```

Пример:

```text
[https://ablakin.example/u/alex](https://ablakin.example/u/alex)
```

## 5.2. Альтернативный URL

```text
/profile/{userId}/wall
```

Основным для пользователей должен быть короткий URL по имени.

## 5.3. Требования к имени пользователя

Имя пользователя должно:

- быть уникальным;
- содержать латинские буквы, цифры и символ `_`;
- иметь длину от 3 до 24 символов;
- не содержать запрещённых слов;
- не совпадать с системными маршрутами;
- не изменяться чаще одного раза в 30 дней.

Зарезервированные имена:

```text
admin
api
login
register
settings
support
help
world
economy
referrals
system
official
```

Отображать:

- владения;

Пользователь может размещать:

- достижения;
- объявления;
- результаты конкурсов;

- приглашения в поселение;
- отчёты о развитии.

На стене владельца должна быть кнопка:

```text

```

```text
Пригласить друзей через эту стену
```

Для владельца стены:

```text

```

Кнопка должна открывать:

- копирование URL стены;
- Telegram;
- Discord;
- email;
- системное меню «Поделиться»;
- QR-код.

# 7. Атрибуция посетителя стены

## 7.1. Общий принцип

Если новый пользователь открыл стену пользователя A и затем зарегистрировался, система может привязать нового пользователя к A.

Реферальная связь создаётся только при выполнении условий:

- владелец стены существует;
- владелец стены имеет право приглашать;
- посетитель ранее не зарегистрирован;
- посетитель не является владельцем стены;
- не обнаружен цикл;
- не превышен срок хранения атрибуции;
- отсутствуют критические антифрод-сигналы.

## 7.2. Временный wall token

При открытии стены сервер создаёт временный токен:

```text
wall_visit_token
```

Токен хранится:

- в cookie;
- в session storage;
- на сервере;
- в зашифрованном или подписанном виде.

Токен не должен содержать открытые персональные данные.

Пример внутренней структуры:

```json
{
  "wallOwnerId": "user-123",
  "visitId": "visit-456",
  "createdAt": "2026-09-30T20:00:00Z",
  "expiresAt": "2026-10-30T20:00:00Z",
  "signature": "..."
}
```

## 7.3. Срок атрибуции

Рекомендуемый срок:

```text
30 дней
```

Если пользователь зарегистрировался в течение 30 дней после первого посещения стены, связь может быть создана.

## 7.4. Последняя или первая стена

Для простоты и защиты от спорных ситуаций использовать правило:

```text
засчитывается первая валидная стена,
которую посетил пользователь перед регистрацией.
```

После регистрации изменить владельца стены нельзя.

Если пользователь явно нажал кнопку:

```text
Присоединиться к этой стене
```

то выбранная стена получает приоритет перед предыдущей пассивной атрибуцией, если регистрация ещё не начата.

# 8. Явное действие «Присоединиться»

На стене пользователя должна быть кнопка:

```text
Присоединиться к этой стене
```

После нажатия:

1. показать имя владельца;
2. объяснить бонус;
3. установить wall token;
4. перевести пользователя на регистрацию;
5. запомнить источник;
6. показать владельца после регистрации.

Пример текста:

```text
Вы присоединяетесь к стене пользователя Alex.

После создания персонажа и выполнения первых игровых действий вы получите:

+50 кредитов
+5 рейтинга
```

Для юридической и пользовательской прозрачности рядом должна быть ссылка:

```text
Как работает приглашение
```

---

# 9. Приоритет способов атрибуции

Система должна использовать следующий приоритет:

```text
1. Явное нажатие «Присоединиться к этой стене»
2. Wall token из активной сессии
3. Первая посещённая стена за последние 30 дней
4. Отсутствие пригласившего
```

Если пользователь ранее посещал несколько стен, система не должна случайно менять владельца связи.

---

# 10. Условия для владельца стены

Чтобы получать награды, владелец стены должен:

- иметь подтверждённый email;
- завершить стартовое обучение;
- иметь активный аккаунт;
- иметь возраст аккаунта не менее 3 дней;
- не иметь блокировок;
- не находиться под критической антифрод-проверкой;
- иметь публичную стену;
- не отключить участие в приглашениях.

Для пользователя это отображается кратко:

```text
Чтобы приглашать пользователей, подтвердите email и завершите обучение.
```

---

# 11. Условия для приглашённого пользователя

Пользователь считается активным приглашённым после выполнения условий:

1. открыл стену пользователя;
2. зарегистрировался;
3. подтвердил email;
4. создал персонажа;
5. завершил стартовое обучение;
6. выполнил минимум 3 игровых действия;
7. не был заблокирован;
8. не создал дубликат существующего аккаунта.

Примеры игровых действий:

- открыть карту;
- выбрать стартовую территорию;
- получить первый участок;
- создать первый предмет;
- выполнить стартовое задание;
- построить объект;
- открыть комнату;
- посетить событие.

# 12. Реферальные уровни

## 12.1. Первый уровень

Пользователь B зарегистрировался после посещения стены пользователя A.

```text
A → B
```

A получает полную награду.

## 12.2. Второй уровень

Пользователь C зарегистрировался после посещения стены пользователя B.

```text
A → B → C
```

B получает полную награду.

A получает уменьшенную награду.

## 12.3. Ограничение глубины

Максимальная глубина:

```text
2 уровня
```

Связи третьего и последующих уровней не создаются для расчёта наград.

# 13. Система наград

## 13.1. Рекомендуемая конфигурация

| Событие | Владелец стены | Приглашённый |
|---|---:|---:|
| Регистрация | 0 | 0 |
| Подтверждение email | 0 | 0 |
| Создание персонажа | 0 | 0 |
| Выполнение 3 действий | +100 кредитов, +10 рейтинга | +50 кредитов, +5 рейтинга |
| Активность через 7 дней | +25 кредитов, +3 рейтинга | +25 кредитов, +2 рейтинга |
| Приглашение второго уровня | +25 кредитов, +3 рейтинга | — |

## 13.2. Схема первого уровня

После квалификации приглашённого пользователя:

```text
Владелец стены получает:
- 100 кредитов;
- +10 рейтинга.

Приглашённый пользователь получает:
- 50 кредитов;
- +5 рейтинга.
```

## 13.3. Схема второго уровня

Если приглашённый пользователь B пригласил пользователя C:

```text
B получает:
- 100 кредитов;
- +10 рейтинга.

A получает:
- 25 кредитов;
- +3 рейтинга.
```

## 13.4. Задержка награды

Для снижения накрутки награда должна иметь задержку:

```text
Рекомендуемая задержка: 48 часов
```

В интерфейсе отображать:

```text
Награда подтверждена.
100 кредитов будут доступны после проверки.
```

Можно разделить награду:

```text
70 кредитов — после квалификации
30 кредитов — после 7 дней активности
```

Для пользователя отображать общую сумму:

```text
Всего: 100 кредитов
Начислено: 70
Ожидается: 30
```

# 14. Кредиты

## 14.1. Назначение

Кредиты используются для:

- покупки предметов;
- строительства;
- оплаты игровых действий;
- участия в конкурсах;
- открытия косметических возможностей;
- получения услуг мира.

## 14.2. Правила

- кредиты начисляются только сервером;
- каждое начисление записывается;
- нельзя начислить одну награду дважды;
- отмена выполняется обратной транзакцией;
- доступность кредитов учитывает статус награды;
- ожидающие кредиты нельзя тратить.

## 14.3. Статусы кредитной награды

```text
PENDING
APPROVED
RELEASED
REJECTED
REVOKED
LIMIT_REACHED
```

# 15. Рейтинг

## 15.1. Назначение

Рейтинг отражает качество приглашений, а не только количество просмотров стены.

Рейтинг влияет на:

- место в таблице лидеров;
- реферальный статус;
- достижения;
- титулы;
- косметические награды;
- отображение в профиле;
- участие в специальных конкурсах.

## 15.2. Начисление рейтинга

```text
Активный приглашённый 1-го уровня: +10
Активный приглашённый 2-го уровня: +3
Активность приглашённого через 7 дней: +3
Достижение приглашённым 3-го игрового уровня: +5
```

## 15.3. Ограничения рейтинга

```text
Максимум за сутки: +100
Максимум за месяц: +1 000
```

Рейтинг не списывается за обычную неактивность.

Уменьшение рейтинга допускается только при:

- аннулировании недействительной связи;
- выявлении самореферала;
- блокировке фиктивного аккаунта;
- нарушении правил.
