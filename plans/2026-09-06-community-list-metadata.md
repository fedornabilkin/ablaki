# Данные для общих списков сообщества

## Цель и контекст

Обеспечить SPA полным списком онлайна, признаком активности пользователей и счетчиком комментариев темы. Учет активности остается в временном файловом кеше, без таблиц и миграций.

## Группа A: API

- [x] A1. Добавить all=1 к GET v1/users/online для полного публичного массива без пагинации, сохранив прежний контракт.
- [x] A2. Добавить is_online в DTO пользователя из фактического кеша активности.
- [x] A3. Добавить comment_count в API-модель темы, подсчитывая только активные сообщения сервером.

## Группа B: Проверка

- [x] B1. Проверить полный список более 20 пользователей, приватность и активные/неактивные состояния.
- [x] B2. Проверить реальные счетчики комментариев/просмотров, включая скрытое сообщение.
- [x] B3. Пройти auth-response, frontend-api-routing, frontend-lists и PHP 7.3 lint измененных файлов.

## Критерии готовности и ограничения

Проверки прошли на PHP 7.3.33 с изолированными SQLite и runtime. Production-данные и миграции не менялись. Изменения локальные, публикация не выполнялась.
