# Подключение «5 яблок»

Цель: подключить существующие правила игры к рабочему интерфейсу на test.
Контекст: история уже подключена; проверяем игровой цикл, серверную пагинацию и надёжность списания/возврата.

## Группа A: Контракт и операции
- [x] A1. Добавить пагинацию списков, последний раунд и серверную сумму выплаты в DTO.
- [x] A2. Проверять актуальное состояние партии/счёта в транзакции; атомарно отменять свободную партию.
- [x] A3. Проверить полный цикл двух игроков, скрытые ходы, повторы, отказы и откат при ошибке истории.

## Группа B: Выкладка
- [x] B1. Пройти PHP 7.3 lint и изолированные release-проверки.
- [ ] B2. Влить в test, проверить CI и серверные маршруты.

Критерии: победитель получает две ставки минус 5% комиссии ровно один раз; скрытый ход не раскрывается до ответа; тесты не изменяют живые аккаунты.

Проверки: PHP 7.3 lint и восемь SQLite release-наборов. Новый five-game.php проходит полный REST-цикл с победой каждой роли, 25 комбинаций раунда, видимость скрытого хода, повторы/запоздалые round_id, чужую отмену, возврат, откаты при отказе истории/комиссии, пагинацию и поиск. Проверки FOR UPDATE на PostgreSQL/MySQL остаются отдельной проверкой перед production. Миграции/инфраструктура не изменены.
