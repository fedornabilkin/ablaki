# Production-релиз

Цель: выпустить проверенные в test изменения по прямому указанию владельца.
Контекст: release/09-production собрана от master из рабочих веток и отдельных ранее проверенных коммитов; test в master не сливается. До дополнительных проверок дерево релиза полностью совпало с test.

- [x] A1. Собрать состав релиза и сверить с test.

## Группа B: Production
- [ ] B1. Влить release-ветку в master и выполнить production deploy.

Критерии: проверенная версия backend работает на production, игровые проверки не используют живые счета.
