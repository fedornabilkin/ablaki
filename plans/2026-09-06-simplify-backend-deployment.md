# Возврат к git pull и make up

## Цель и контекст

По требованию владельца убрать усложнение автоматизации. Ошибка `Pool overlaps`
возникла в добавленном предварительном `compose run`, до обновления checkout.
Продолжать работу в master. MySQL production и PostgreSQL test уже существуют.

- [x] A2. Убрать требование артефакта, API URL и сборку runtime из пути публикации.
- [x] A3. Убрать общий фиксированный IPAM, вызывающий конфликт новых сетей.
- [x] A4. Сравнить Makefile/runtime с исходным запуском; оставить миграции, marker для frontend health и запуск PHP/nginx, убрать определение/запуск БД и force-recreate.

## Критерии готовности

Серверный деплой запускает обновление checkout и `make up`; до них нет
Docker-команд, изменения `.env`, vendor или подключения БД. Успешное выполнение
на реальном VPS подтверждается отдельно результатом нового запуска Actions.

Полный откат Makefile и entrypoint не применяется: старый `up` запускал все
сервисы, включая Composer 1.8/PostgreSQL на MySQL prod, а старый entrypoint
делал Yii init Development и не останавливался при ошибке миграций. Текущие
исправления PHP 7.3.33, API и CORS сохранены; пересборки PHP при деплое нет.
