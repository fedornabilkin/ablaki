# Активность и фонд главной

Источник: http://94.250.251.94:3181/forum/read/64, сообщение 141 от fedornabilkin.
Цель: показывать фонд на сегодня/завтра, расчётную долю пользователя, посетителей за день и фактические ежедневные бонусы.

## Группа A: API
- [x] A1. Сохранять посещения дольше онлайн-окна и отдавать список за день по Москве с поиском/пагинацией; учитывать также входы по last_login_at.
- [x] A2. Отдавать фактические выплаты everyday из history_balance с безопасным публичным профилем.
- [x] A3. Считать фонд из однозначно кредитных комиссий и долю по положительному рейтингу; личные данные доступны только на my-fund.
- [x] A4. Проверить временные границы, валюты, авторизацию, сериализацию и существующие release-наборы.
- [x] A5. Выполнить test deploy.

Проверено: PHP 7.3 lint, восемь release-наборов, проверки валют/границ суток/гостевого и личного API. [Test CI 35008649441](https://github.com/fedornabilkin/ablaki/actions/runs/35008649441) успешен, выложен 081e1d9. HTTP: fund 200, visitors 200 (11 пользователей на момент проверки), recipients 200 (0 реальных выплат сегодня); my-fund без авторизации 401, с авторизацией 200. Новых начислений и изменений production не выполнялось.

Правила: сегодня — комиссии вчера, завтра — сегодняшние; доля округляется вверх, как на старой главной. Комиссии exchange без валюты исключены. Это прогноз, текущая выдача 1 Cr не изменяется. Вопрос о возвращении прежней выдачи задан владельцу.
Ограничение посещений: новые активности сохраняются в суточном presence-кэше; очистка кэша оставляет только записи входов из last_login_at. Данные активности до обновления сверх прежних пяти минут восстановить нельзя.
