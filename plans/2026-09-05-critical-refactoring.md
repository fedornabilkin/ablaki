- [ ] D1. Выполнить актуальный Composer audit и выбрать совместимые поддерживаемые версии PHP/Yii.
- [ ] D2. Проверить обновление окружения и миграции на копии данных с восстановлением backup.

- [ ] D4. Подготовить отдельный тестовый PostgreSQL; не использовать production-БД.
- [ ] D5. До деплоя в кластер заменить временный файловый кеш онлайна общим хранилищем активности для всех экземпляров приложения.
- [ ] D6. Проверить единый список и счетчик онлайна при распределении запросов между экземплярами, перезапуске экземпляра и истечении окна 5 минут; зависит от D5.

Файловый кеш онлайна в `@runtime/presence` — временное решение для одного сервера.
При кластерном деплое локальные файлы и файловые блокировки не разделяются между
экземплярами приложения: каждый видит только свою часть активности. Поэтому
текущая реализация не обеспечивает корректный общий онлайн в кластере; D5–D6
обязательны до горизонтального масштабирования. Подробности текущего решения:
[исправление авторизации и онлайна](2026-09-06-auth-presence-fix.md).
